## Round A+C（commit `1039a51`）：beamer 缓存门+零分配、同步打包串缓存

- **变换签名门**：World 每帧收集全动态体变换逐位快照（Float64Array 复用，O(动态体)≈40×3 读）；
  与上帧全等且 epoch（freeze/melt/体销毁三类突变自增）一致 ⇒ 本帧 raycast 与上帧**逐位相同**，
  复用折线并**重放照明标记**（标记语义=每帧覆盖写，重放值恒等→lightpusher 读值不变→物理等价）。
- **零分配**：raycast 回调上下文化（rcCtx 单例）、反射算术临时向量复用（tmpFrom/To/Dir/B/F）、
  折线对象池、照明标记数组池。
- **Round C**：Beamer.packed() 打包串坐标缓存（逐位比较未变零构建）；ForestRoom.syncState/
  world.mechSnapshot 切 packed。
- 位级验证：det forest 48/48 + light 40/40 **双锚全绿**（提交前后各跑一遍）；vitest 226 全绿。

| 指标（idle，同机同口径） | 基线 → Round A+C | 变化 |
|---|---|---|
| light 中位步进 | 0.0151 → **0.0109ms** | **-27.8%**（对 forest 溢价 135.9%→70.3%） |
| light_02 sync / encode | 0.0129/0.0009 → **0.0092/0.0006ms** | **-28.7% / -33.3%** |
| light_02 heap/600 步 | 8145 → **4506KB** | **-44.7%** |
| light_11 heap/600 步 | 8600 → 6974KB | -18.9% |

口径注记：签名门收益集中在**空载/静置态**（容量语义下的常态房间，r6 容量模型 96 房拐点即
按 idle patch 率标定）；玩法态（角色持续移动⇒签名不稳定）raycast 照常重算，收益=分配消除
（GC 压力）+打包串跳构建；scripted 口径基线（Round A 后）溢价 48.5% 已入档。

## Round B（commit 见 git log）：dark 黑幕静态/动态分层

子 agent 并行实施（commit `f96914f`），主会话逐项验证后采纳：

- **实现**：staticHaloRt（同尺寸/位/原点，不上屏）承载 rotmirror r160/wind 双 r90/platform 双 r160
  的静态晕擦除图案（`beginDraw/batchDraw/endDraw` 单批）；脏检测=点亮 key 集合+点亮平台位姿签名，
  一致整层跳过（平台位置入签名是必要修正——平台 state 1 运行时晕随体动，否则违反晕锚语义）。
  每帧主 darkRt：clear→fill→erase(staticHaloRt) 一次→动态仅角色双 r180/lever 杆尖/beamer 源+光束段。
- **API 等价性实证**（实施前 Playwright 最小页实验）：静态层路径 vs 逐晕直接 erase 单晕 diff=0、
  重叠晕区仅 8bit 舍入差（maxΔ<1 灰度，远低于 48 门槛）；RT 作 erase 源经 DynamicTexture.batchList
  官方路径。
- **性能**（页内 A/B，SwiftShader 软渲相对口径，10 平台全点亮态）：静止 **73.2 vs 130.1ms/帧（-44%）**、
  移动 96.9 vs 155.7（-38%）；light_30 每帧 erase 遍数 **22→3**。
- **验证**：typecheck/build ✓；四 dark 关复拍 98.06/99.63/98.20/97.24（≥94.5 达标）；det light
  40/40 位级一致（未碰物理）。
