## 4. 逐项差异解释（按 20 号档 §6 口径）

### 4.1 字号（464a5a9）——"本应变化"项，方向为改善

本轮实测时钟金色数字墨迹盒（金色像素 R>180,G>140,B<120 扫描，(540..760, 0..130) 区域）：

| | x 范围 | y 范围 | 墨迹宽×高 |
|---|---|---|---|
| 原版 | 597-681 | 7-31 | 84×24 |
| 我方 | **597-681（同）** | 67-91 | **84×24（同）** |

- 同宽同高 = 同名义字号渲染像素相同（§6 结论 fontSize/48 缩放律）在本轮数据上直接成立；x 范围逐像素一致还说明字号之外的步进/落位也一致。
- 反证：0.3.29 发版跑（95.11）时我方时钟是 38 号（24×1.6，464a5a9 diff 删除项），墨迹高应为 ~38px vs 原版 24px——该轮字形区匹配率被口径错误压低。**95.11 → 96 的上升量中，这是"按 §6 本应变化"的部分**。
- 教学文字（464a5a9 另一涉及面）特征探针：`tutorial-wg-text` 局部最优偏移 (16,−16)、MAD 6.52——与整幅地形完全同偏移、无独立失配，名义字号下文字落位正确。

### 4.2 相机（29931ad）——参照语义变化，留 16px 取景偏移待产线裁决

多区域局部最优偏移探针（灰度 ±40px 整数搜索，run1 两图，正值=我方内容相对原版向该轴正向平移）：

| 区域 | 偏移 (ox,oy) | 对齐后 MAD |
|---|---|---|
| center-bricks (640,430) | (16,−16) | 5.96 |
| topleft-corner (90,90) | (19,−13) | 3.54 |
| bottom-bricks (640,890) | (16,−17) | 7.55 |
| door-fb (1070,155) | (16,−15) | 4.20 |
| tutorial-wg-text (340,745) | (16,−16) | 6.52 |
| lever (330,640) | (16,−16) | 1.82 |
| clock (640,30) | (0,0)* | 25.64 |
| pause-btn (1245,30) | (37,−18) | 16.83 |

\* 时钟不随世界偏移（见 4.3），该格大部分是背景，(0,0) 无意义。

- **世界内容呈刚体 (右16, 上15~17) 偏移**，与基准最优平移 (6,−6)@480（= 16px 级）互为独立测量吻合。
- 边缘扫描 + 3x 裁剪目检（`TEMP/flashvd/run1/leftedge-*.png`、`door-*.png`，清理前可复核）：我方左黑边 31-32px vs 原版 18px；门框我方高 ~15px 右移 ~17px。
- 机制假设（数字自洽，供产线用 camtrace 裁决，非本槽终判）：
  - `GameScene.ts`：`PAD=32`（L36）→ 世界 = 关卡+2×32 = 1312×992；视口 1280×960 → checkBounds 钳制盒 [640..672]×[480..512]（L988）。弹簧目标 = 玩家中点+PAD（L979），forest_01 出生构型下被钳到角 **(640,512)** → scroll = (0,32) → 关卡画在屏 (32,0)：与实测左缘 31-32、底缘 928（=960−32）吻合。
  - 原版 f60 实测关卡在屏 (18,18)、底缘 941（≈946−阈值削边）→ scroll ≈ (14,14)，即**仍钉在世界中心**（中心 656,496 → scroll (16,16)）。
  - 两侧 scroll 差 (−16,+16) → 内容偏移 (右16,上16)，与特征探针精确一致。
  - f3 时代 (0,0) 的来历：e0d3cdf 显式 `scroll=(16,16)` 对齐原版 `stage=level+16`；29931ad 换成弹簧+钳制后，出生构型的钳制角目标使 scroll 落到 (0,32)，对齐被破坏 16px。
- 分数学影响：零偏移 r48 仅 77.6%（f3 时代该口径 ~95），择优对齐后 96.05——**总分指数对这项系统性偏移近乎失明**（±48 搜索吞掉了它），读数时必须连带看零偏移列。

### 4.3 顶部 HUD 带 74.87%（f3 时代 92.58%）——三因叠加，非新回归

1. 顶部带按**零偏移**计算（脚本口径），4.2 的 16px 全局偏移全额打进该带 → 主因。
2. `#hud-top` DOM 条（role/房间码，fixed top:8px 带面板底）压在画布顶部中央，canvas 元素截图连 DOM 覆盖层一起拍——0.3.23 的 index.html 该 CSS 与现版逐字相同（fdb6485 已核），**两时代同在，非本轮引入**；最差格 (5,0)(6,0) 即其位置。
3. 时钟锚位：我方数字在屏 y 67-91，原版 y 7-31，**恒差 60px**——我方时钟走世界坐标（`bitmapText(clockX, 56,...)` + PAD 世界偏移约定），原版在画布顶部拱饰内；60px ≠ 16px 世界偏移，是独立锚位差。暂停钮探针 (37,−18) 同类（世界偏移+锚位差合成）。归产线裁决。

### 4.4 判定：无真回归证据

地形/门/拉杆/教学文字对齐后 MAD 1.8~7.6、分数 +0.72 以上升、§6 字号项方向为改善——本轮**未发现真回归**；余量全部集中在 4.2 取景偏移与 4.3 HUD 锚位/DOM 覆盖两类系统项。
