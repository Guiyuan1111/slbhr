# r19 · 字体图集重排：进房前子集从 2191×1024 换到 1006×378（2026-10-21）

> 战役第 19 轮。r18 把 Boot 关键路径上那份 1600.3KB 全量字体拆成两代，代价写在它的 §五之二：
> 子集刻意**不动 `.fnt`** ⇒ 幅面必须与全量同为 2191×1024 ⇒ 页面生命周期里挂着**两张 8,974,336B 的解码位图**。
> 本轮把其中一张（进房前那张）的**幅面**换掉：保留字形的帧矩形换坐标紧凑重排，
> 206 条未保留声明全部指向同一块透明块，配一份只改 `x/y` 与 `scaleW/scaleH` 的 `font-prephase.fnt`。
> 产物 242.4KB / 解码 1.45MB（前代 304.5KB / 8.56MB）。度量面逐条不变（`width/height/xoffset/yoffset/xadvance` 一字未改）。
> 零协议、零物理；无损性仍由 r18 的 `prephase-canvas` 五态零容差门禁作证，本轮为它补了换代取证件与 `--reason` 强制。
> 单位口径同 `perf-load`：下文 KB = 1024B、MB = 1048576B。

## 一、量具与判据（四件）

| 件 | 能力 |
|---|---|
| `scripts/font-subset/reflow-measure.mjs`（件0，只测不落盘） | 重排上限量具：逐 texel 核验"帧四周是透明衬边"这条假设（`bandViol`/`outsideViol`/`edgeTouching`），并对 A/A′/B/C/C′/D 六种布局各算候选幅面、解码字节、**真实 PNG 字节**。r19 的取舍全部由这张表定，不靠"图集本就致密"之类的印象 |
| `scripts/font-subset/reflow-prephase.mjs`（件1 生成器） | 重排产物与逐像素自证：区域打包 → 逐字节搬源 → 重编码 → **重解码后再验一遍** → `.fnt` 逐行改写与行级核 → 度量重解析核。`--check` 重建到 `TEMP` 与在库比字节（可复现性），`--dry` 只打印账目 |
| `scripts/e2e/pixel-forensics.mjs`（本轮新增，常驻） | 两张同尺寸 PNG 的逐像素取证：差异数、按通道计数与最大差、均值、**3×3 邻域渐变归属**（把"抗锯齿边上 ±1"与"平坦区成块差异"分开）、α 可比性判定、包围盒与热点行。判据写死：`平坦区有差 = 缺陷`、`α 有差 = 缺陷`、`全落在渐变上且平坦 0 = 可按换代入账` |
| `scripts/e2e/prephase-canvas.mjs`（r18 门禁，本轮加 `--reason`） | 像素与上一批基线不同时**必须**给一句理由，理由直接写进 `manifest.provenance`。此前"换代必须留原因"只是报告里的纪律，基线自己看不出是谁在什么时候为什么换的值——现在换不了静默的 |

`scripts/png-raw.mjs` 本轮扩了 **colour type 2（RGB）** 支持：门禁的基线 PNG 是浏览器截图，正是 RGB 无 α 那一路，
而 `pixel-forensics` 要读的偏偏就是它。解码侧现按 `ch = {6:4, 2:3}` 反滤波，出口统一补成 RGBA（α=255），
`color` 字段保留原类型——**"α 相同"在这种配对上是同义反复**，取证件据此把 α 一栏标 `n/a` 而不是报绿。

## 二、件0：假设核验把"透明边框"路线推翻

r19 开工前的共识是"AngelCode `padding="4,4,4,4"` 声明的是每帧四周的透明衬边，所以重排只要留 ≥1 texel 隔离带即可"。
量具逐字节核验的结果**相反**：`font.png` 里 **258 条有墨字形全部同时命中 `bandViol` 与 `outsideViol`**
（帧墨迹顶到帧矩形边、帧外 1 texel 读到的是**邻帧的墨**）。衬边是"声明"，不是"事实"。

于是三条路线当场判死，一条留下：

| 路线 | 候选 | 结论 |
|---|---|---|
| A 全量·原样重排（只搬帧矩形） | 2191×1024 → 帧密度 94.79% | 采样邻域变了，等价性无从谈起 |
| A′ 全量·环带重排 | **1598×1453 ＝ 8.86MB**（今日 8.56MB，texel **−3.49%**） | 环带必须一起搬 ⇒ 全量重排是**内存负收益**，不实施 |
| B/D 裁到墨迹包围盒（＋1px） | 895×2143＝7.32MB / 880×343 | 要改写 `xoffset/yoffset`（度量面变了），且"裁掉的像素"里正含被邻帧采到的墨 ⇒ 排除 |
| **C′ 子集·环带重排＋共享透明块** | **1006×377＝1.45MB**，PNG 225.8KB | **唯一站得住的收益面**，本轮实施 |

`A′` 那一行是本轮最值钱的一次否定：它把 r18 报告里"两张 8.97MB → ≈1–2MB"的期望**在全量那一半上判为不可达**。
进房前这一半能换，游戏内那一半（260 字全用）换不了——除非接受观感层面的采样级别变化，那已不是"只动坐标"。

另一个必须记的量具口径坑：**POT×POT 拒绝**。Phaser 上传纹理时 `generateMipmap = IsSizePowerOfTwo(w,h)`
（`node_modules/phaser/src/renderer/webgl/wrappers/WebGLTextureWrapper.js:344`），今日 2191×1024 非 2 的幂 ⇒ 无 mipmap、纯 LINEAR。
若重排候选恰好凑成 2 的幂对，采样级别就从 LINEAR 变成 LINEAR_MIPMAP_LINEAR——那不是"只动坐标"。
`pack()` 因此多了 `forbidden(w,h)` 回调，量具与生成器共用同一口径层（`prephase.mjs`），避免两套数字漂移。

## 三、实施（件1，四笔提交）

**`99fcb30`｜生成器**。三条不可让的等价约束全部是脚本里的**硬断言**，不是注释里的承诺：

1. **区域＝帧矩形 ∪ padding 环带，逐字节搬源**。换邻居必须把环带一起搬走，否则"LINEAR 采到的字节与今日相同"不成立（成因见 §二）。
2. **墨迹守恒**。上一代子集的每一个非零像素都落在保留区域内（实测区域外 0 个），故重排产物＝上一代的一次**布局置换**：既不新增墨、也不丢墨。
3. **幅面不得同时为 2 的幂**（同上）。

落盘前还跑这些核：区域重叠 `claim()` 逐 texel 核、环带越出源画布即抛（件0 实测 0 处）、
重编码后**重解码**再核尺寸/块序（`IHDR,pHYs,iTXt,cHRM,IEND` 逐字符相同）/样本无损、
逐区域逐行与源字节全等、区域外残留 0、每条声明的重排后矩形不越出画布；
`.fnt` 侧只改写 `<char>` 的 `x=`/`y=` 与 `<common>` 的 `scaleW`/`scaleH`（261 条 `<char>` 行），
遮掉这几项后**与源逐行逐字节相同**，再重解析核 `width/height/xoffset/yoffset/xadvance/page/size/lineHeight/base/pages/padding`
与重复 id 结构（id=32 两条 0×0）逐条不变。

产物账（`node scripts/font-subset/reflow-prephase.mjs --check` 原样输出）：

```
进房前文案字符 75：有字形 53（帧 52 个）/ 无字形 22
声明 260 条 = 保留 52 + 未保留 206 + 0×0 2（未保留者全部指向同一透明块 98x101）
上一代（composeSubset 内存复现）2191x1024 304.5KB（解码 8.56MB） 墨迹 316,765
重排产物          1006x378     242.4KB（解码 1.45MB） 墨迹 324,803 帧密度 69.97%
搬运 328,458 texel（区域＝帧 ∪ 4px 环带，逐字节＝源）
省：解码位图 7.11MB（−83.1%）/ PNG 62.1KB（−20.4%）
可复现性：png 字节一致 ✓  fnt 字节一致 ✓
```

墨迹那条差额要说明口径：**8,038 是重复量，不是新增墨**。源里同一像素若同时属于两个保留区域（A 的环带压进 B 的帧），
重排后它被搬两次——各自服务自己那一帧的邻域采样。所以守恒式取"逐区域墨迹之和"，不能取"总墨迹相等"。
`324,803 − 316,765 = 8,038` 正是这个邻域重复量，`--check` 每次都把它算出来核一遍。

**`02841b0`｜产物**。`font-prephase.png` 311,836B → 248,196B，新增配对的 `font-prephase.fnt`。
248,196B 里 **16,964B 是从 `font.png` 原样带过来的辅助块**（`pHYs` 21 + `iTXt` 16,899 + `cHRM` 44），
纯像素侧（`IHDR`+`IDAT`+`IEND`）是 231,232B ＝ 225.8KB。件0 量具那条 C′ 臂预估的正是 225.8KB——
但两者**并非同一份布局**：量具的透明块取 `+2·spacing`（94×97，候选 1006×377），生成器与保留区域同口径取
`+2·ring`（98×101，产物 1006×378）。差的那一行换不来压缩收益，两侧像素侧只差 0.01KB，
所以量具的预测在 0.1KB 内兑现，但没有"逐字节相同"这种更强的话可说。
`iTXt` 是 AngelCode 生产者写的元数据块，本轮**刻意不删**：
删了省 6.7%，但"块序与源一致、辅助块原样保留"这条 r18 定的可复现口径就要一起改，不值当（列入 §七 挂账）。

**`09c8a2e`｜client 装载改指成对产物**：
`this.load.bitmapFont(FONT_MAIN, ".../font-prephase.png", ".../font-prephase.fnt")`（`BootScene.ts:134`，前代第三个参数是 `font.fnt`）。

**`fd4bcdb`｜静态网改判重排语义**（`font-prephase.test.ts` 11 例 → 12 例）。新增的 r19 组六条断言直接读产物字节：
度量逐条相等（只允许 `x/y` 变）、保留区域逐字节＝源、未保留声明矩形内 0 墨、POT×POT 拒绝、幅面确实缩小、保留 53 字。
Boot 那条关键路径断言同时改判：现在钉的是**整条 `bitmapFont(FONT_MAIN, png, fnt)` 调用**，
并全局计数 `font.png`/`font.fnt`/`font-prephase.fnt` 三处字面量各只允许出现在它该在的装载通道里。

顺带修掉本轮自己踩到的两个**跨代耦合**（同一类错误，都是"参照系指向某一代产物"）：

- 生成器原先 `loadFontAtlas(CUR_PNG, fnt)` 读在库子集当"上一代"参照——重排跑过一次之后这张图已是新布局，
  按源坐标去裁它直接崩。改为 `composeSubset` **在内存复现上一代**，并加在库代别核对（同尺寸才比字节，否则只报"已重排"）。
- 件0 量具 `reflow-measure.mjs` 有同一处读盘（C/C′ 两臂的"今日子集"参照），r19 落地后再跑就抛
  `矩形 (2031,280,85,92) 越界 1006x378`。本轮改成同一口径的内存复现，在库那代只作事实打印。**量具必须能量任何一代**，
  否则它的结论无法复核。
- 生成器归属改判：`build-font-prephase.mjs`（r18，产"原坐标＋清零"图）现在带 `guardReflowGeneration()`——
  同目录存在配对 `font-prephase.fnt` 即拒写，实测退出码 1、理由一句到位。否则旧布局 png 配新坐标 fnt 会静默产出**错位字**。

## 四、换代取证：像素为什么变了、变的是什么

门禁换过一次基线，所以这一节是必需的。`prephase-canvas` 五态差异（`scripts/e2e/pixel-forensics.mjs`，机器可读结果入库在
`benchmark/results/prephase-canvas/r19-reflow-evidence/`）：

| 态 | 差异像素 | 按通道 R/G/B（最大差） | 均值 | 3×3 有渐变 | 平坦区差异 |
|---|---|---|---|---|---|
| menu | 1,944 | 642/712/837（全 1） | 0.376 | 1,944（100.00%） | **0** |
| temple | 31 | 16/13/2（全 1） | 0.333 | 31（100.00%） | **0** |
| temple-numbers | 270 | 89/145/45（全 1） | 0.344 | 270（100.00%） | **0** |
| settings | 17 | 5/11/8（全 1） | 0.471 | 17（100.00%） | **0** |
| credits | 373 | 93/269/119（全 1） | 0.430 | 373（100.00%） | **0** |
| **合计** | **2,635**（0.018%） | 最大差恒为 **1** | ≈0.38 | **100.00%** | **0** |

机制说得清，不是"画质折衷被放容差"：帧矩形换坐标 ⇒ **UV 浮点重舍入**。字形在页面上的位置、字号、行距、字距全部由
`xoffset/yoffset/xadvance` 决定，那些字节没动；动的是纹理坐标落到图集里的哪一块，`v/2191` 与 `v/1006` 的舍入路径不同，
于是 LINEAR 滤波在**边缘 texel** 上取到相邻一档权重。±1/255 只会出现在"本身处于渐变（反锯齿斜坡）上"的像素，
平坦区（同色块内部、纯背景）不可能被舍入挪动。实测正是这个形状：**100.00% 落在渐变上、平坦区 0 个**。
若是搬错字框、把某帧清零、或被邻帧墨污染，留下的是**成块的平坦区差异**，一处都不会有——所以这一栏是本轮真正的判据，
"总差异像素少"本身不说明任何事。

两条如实的口径限制，写进证据目录的 README，不在报告里含糊过去：

- **α 未被本门禁覆盖**。基线 PNG 是浏览器截图（colour type 2，不含 α），"α 相同"在这种配对上是同义反复。
  透明度由资产层断言负责：重排把每个保留字形的**区域（含 α 四通道）逐字节搬源**，未保留声明指向的透明块全零。
- `magick compare` 报的 AE（1945/32/270/17/373 ＝ 2,637）比 `png-raw` 口径多 2 个像素：两套解码器对极个别像素取整不同。
  **门禁判据始终是 PNG 字节的 SHA-256，不是 AE**。

换代理由已进 `manifest.provenance`（`--save --reason` 强制），其中就写着上面这张表与机制一句话。

## 五、收益

|---|---|---|---|
| `font-prephase.png` 传输 | 311,836B（304.5KB） | 248,196B（242.4KB） | **−63,640B（−20.4%）** |

### 五之一、位图账同场 A/B/A（比 r18 那次更干净的做法）

r18 的 A/B 靠回退工作树重建，两条臂的 JS bundle 也各自换了代号；本轮改成**只换 `packages/client/dist` 里那份资产对**
（`font-prephase.png` ＋ 对应的 `.fnt`），三次运行的 **JS bundle 逐字节相同**，顺序 prev → reflow → prev，
量具 `perf-resident`（纹理逐源 `w·h·4`、强制 GC 后堆值）：

| 臂（dist 资产） | menu | temple 首入 | temple 重进 | temple 三进 | game 开局 | temple 离房后 | 字体纹理账目 |
|---|---|---|---|---|---|---|---|
| a `prev` | 90.95 | 105.88 | 105.88 | 105.88 | 100.33 | 105.88 | `font` 8.56 ＋ `font-full` 8.56 |
| b `reflow` | **83.84** | **98.77** | **98.77** | **98.77** | **93.23** | **98.77** | 只剩 `font-full` 8.56（`font`＝1.45，已掉出 top6） |
| c `prev` | 90.95 | 105.88 | 105.88 | 105.88 | 100.33 | 105.88 | 同 a |

- **同臂复跑 texMB 六态逐位相同**（a=c 全等）⇒ 纹理台账这条轴没有机器漂移，跨臂那条差才是干净的可主张量。
- 每一态都低 **7.10~7.11MB**（game 态 100.33−93.23 的 7.10 是 MB 保留两位的舍入）；字节差恒为
  8,974,336 − 1,521,072 ＝ **7,453,264B**，与 §三 的幅面算术严格相等。游戏内与离房后同量，
  说明省下的是**整张位图的驻留**，不是某一次解码的瞬时峰。
- **强制 GC 后的堆不随这条轴动**：三臂 18 个 `heapGCMB` 读数里 17 个逐位相同，唯一一处是 a 臂
  temple 三进 27.3 vs b/c 的 27.2（0.1MB 舍入位）。`createImageBitmap` 的位图不进 JS 堆，
  所以这张 8.56MB 只能从纹理口径看见。**只看堆会得出"驻留没代价也没收益"的错误结论**——
  r18 把它记成堆附近的隐性代价本身就不精确，本轮按纹理账归位。
  对照：GC 前的 `heapRawMB` 跨臂跨跑本来就飘（temple 首入 52.0 / 43.1 / 42.9），进一步说明只有 GC 后与纹理两个口径可读。
- 前代那两条 `font`/`font-full` 同为 8.56MB 的读数，是 r18 §五之二"位图翻倍"的第一次直接实测。

## 七、挂账与下一步

1. **全量字体那 8.56MB 本轮判为不可动**（§二 A′ 负收益）。真要动，只有一条路：接受采样级别变化或改度量面，

   收益小、动的是可复现性判据，暂不排。
