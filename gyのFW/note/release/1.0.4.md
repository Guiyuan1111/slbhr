# 1.0.4 — 窄屏 HUD 自适应

> 发布日期：2026-10-29 ｜ 上一版 1.0.3

## 修了什么

手机竖屏下顶部联机信息栏（房间码 / 复制邀请链接 / 等待提示）被左右裁切。量化实测：

| 视口 | 修复前 | 修复后 |
|---|---|---|
| 320×568 | 溢出（房间码 item 宽 344px） | 80..240 ✓ |
| 390×664（iPhone 12 竖屏） | **左 -113 / 右 503**，房间码与邀请钮被裁 | 98..293 ✓ |
| 414×896 | 溢出 | 104..311 ✓ |
| 844×390 横屏、平板、桌面 | 正常 | 不变（仍是单行） |

根因：`#hud-top` 居中定位 + 子项 `white-space: nowrap` + 无宽度上限，内容宽度（617px）
超过视口时向两侧等比溢出。

修法：`max-width: calc(100vw - 16px)` + `flex-wrap: wrap` + `justify-content: center`；
≤560px 加一档媒体查询缩字号与内距；320px 档 `#hud-room` 允许行内折行（否则它作为
flex item 以 min-content 撑出容器）。

## 验证

- 六档视口回归（320 / 390 / 414 / 844 / 810 / 1280）全部不溢出、房间码可见、邀请钮在视口内
- 桌面端外观零变化（仍单行，宽度 624px vs 修复前 614px）
- 353 个单测全绿
- 包内 9 项验收全绿
