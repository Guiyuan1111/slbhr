# 1.0.3 — deploy.sh 帮助输出修复

> 发布日期：2026-10-29 ｜ 上一版 1.0.2

## 修了什么

`./deploy.sh --help` 在开发树（三部 `data/` 并存）下会被「本部识别」拦掉，输出
`✗ 无法从 data/ 认定本部`。帮助文本本身是安全的、不依赖任何环境判断，因此把
`-h/--help` 的处理提到参数解析最前。

分发包里（只有一部 `data/`）原本不受影响，但这属于「看一眼用法」都做不到的体验缺陷，
与部署是否成功无关，故单独出一版。

## 其余

内容、玩法、验收项与 1.0.2 完全相同。已按 1.0.2 完成部署的实例无需升级。
