# 0.3.2 · 性能优化 + 装饰复刻（实玩反馈第二批）

> 2026-10-05。基于 0.3.1 实玩反馈：部分情况掉帧 + 装饰密度低于原版。

## 性能

1. **HUD/时钟 setText 缓存**：Phaser Text.setText 无条件重绘 canvas 纹理——时钟与红/蓝/银计数器此前每帧重绘（60 次/秒），现仅值变化时写入。这是"部分情况掉帧"的主嫌疑。

## 装饰复刻（G12 清账）

2. **decorate() 忠实移植**：替换 mulberry32 近似撒点——原版算法全量落地：seedrandom("ASDFA")（官方模块从 init.js @1826037 起 2717 字节提取封装，序列位级一致）、z()=round(3r+3.5) 行列步进、7×7 窗口搜索（含已选邻域去重）、BoxedDevice 家族 2×2 占位、O/X/A/V/T 分派规则（变体与旋转用 Math.random——原版亦然）。装饰密度/分布现与原版一致。
