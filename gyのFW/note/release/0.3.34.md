## r8 · 点击→Game 场景切换链（实施，`3313403`+`9799145`）

- 件1 连接忙期画布冻结：setBusy(true)→`phaser.loop.sleep()`+floaty 暂停（spinner 保留），唤醒双路兜底（enterGame 的 bgWarmSettled 前 + setBusy(false)）；wake 定位经实测勘误（早醒的"唤醒税"会插进 fetch 段）。
- 件2 `waitForLevelId` 50ms 轮询→onStateChange 事件驱动；件3 temple.json 页面级单例+bindUi 预取（消除关键路径 ~30ms 与 GameScene.create 重复抓取）；件4 `fetchLevel` 客户端缓存（同关重进零拉取）。
- **换肤性能税归档**：石板大厅幕布 backdrop-filter+floaty 在无 GPU 合成环境连接窗 +364ms/+55%（pre-skin worktree A/B + CSS 注入 A/B 实证）——连接期已回收，驻留期留真 GPU 口径（r9 挂账）。
- 勘误两条入档：量具驻留判定洞（"300ms 静默"≠落定，须锚定 ground 纹理就绪）；matchmake 段双峰波动=点击派发/输入管线+房间累积噪声（同页手动 POST 仅 ~3ms 实证，与改动无关）。
