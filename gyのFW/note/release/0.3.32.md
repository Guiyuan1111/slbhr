## 游戏本体

- **游戏内音频批并入 Menu 驻留期后台暖装**（`567b2d3`）：18 键（磁盘实测 2.0MB，勘误旧档 2.8MB）跟随 r5 四图集同一暖装队列+落定门，GameScene.preload 保留兜底声明（已入 cache.audio 键静默跳过，不双载）。音频就绪点从"点击进 Game 后才装"提前至 **Menu 驻留 +941ms**，驻留后点击→Game 409ms；冷启 Menu 传输/请求数 3674KB/14req 与 0.3.31 逐位相同（零冷启代价），进 Game 总传输 6899KB 不变。

## 量具与工具链（benchmark/）

- **perf-capacity.mjs 容量基准**（`8ba9507`）：N 房×2 模拟客户端阶梯爬载，三重降级判据+崩溃留档。拐点 **96 房/192 客户端**（patch 到达率破 54/s；降级形态=patch 网格变粗非物理超步，128 房时漂 ≤0.34%）；CPU 12.55%+0.644%/房、RSS 126MB+1694KB/房；部署建议 **≤64 房/实例**、横向分片为唯一规模化路径。
- **perf-determinism 门禁并行化**（`4a6eb60`+`10c6400`）：关间 worker 池（cap 4+逆序派发），48 关门禁 4.05→2.27s（-44%）；r0 快照=串行回退=并行三方 combined sha 逐字同（判据零变化）；堵 DET_WORKERS 非法值"零行静默绿"红线漏洞；typecheck `--incremental` 2.31→1.42s。
- **perf-client 强化**（`ab68e0e`+`c5f95eb`）：CDP 远程真机模式（--cdp/--host，裸机金标准）、`--gpu` VM 内真 GPU 模式（vmwgfx 真显示+--ignore-gpu-blocklist，renderer=SVGA3D 实证；GPU"架构死路"旧判系 Chromium 黑名单所致，勘误归档）、渲染段细分探针（drawcall/绑定/混合/flush，零分配缺省开）+`--dumpdl`。
- **font 子集化工具族**（`278cbfb`）：四源字符普查 CLI+再生工具+字符清单+4 断言防护测试。实测方案 A 仅 -5.2%（图集 2191×1024 本就致密，保留字形占声明面积 94.79%），低于 20% 停止线——**资产零改动，工具休眠入库**；未来文案大改可一键重评。

## 测量与勘误（负结论归档，防重复立项）

- 容量挂账归因（`a21b178`）：每房边际 CPU 6.4ms/s 拆面闭合（移动 44%/出站 patch 23%/模拟 14%/房间 10%/input 9%）；stime 主导=loopback ws 发送内核成本（VMware 客机放大）→96 房拐点口径偏保守，部署预算按收发字节加权（重关卡集群 ~1/2~1/3）。
- 渲染段 JS 面理论地板（`535abb6`）：--gpu 口径整帧单批（drawcall 1.00/帧、blend 0、bind 5.6=带数下限、renderAvg≈帧预算 1.4%），四候选优化方向全数据驳回；剩余杠杆在 present/合成器/负载调度面（项目代码边界外）。
- 勘误三条：GPU"架构死路"实为 Chromium 黑名单（`aea9d69`）；44fps 系基准窗负载污染非显示刷新封顶（xrandr 60Hz）；font.png 实为 2191×1024 非 2048²。性能战役总账扩为七轮：`note/report/perf/2026-10-18-campaign-summary.md`。
