# 0.3.21 · 性能专项（物理 step −90% / 加载传输 −30%）

> 2026-10-08。四轮性能优化：服务端物理 step、快照路径量化、客户端加载、装载/内存验证。
> 完整对比报告：[note/report/perf/2026-10-08-perf-optimization.md](../report/perf/2026-10-08-perf-optimization.md)。

## R1 · 服务端物理 step（−90.4%）

- **根因**：引擎 vendor bundle 在 node:vm 沙箱求值，vm 上下文的全局代理属性访问慢路径使
  同一负载慢 ~7 倍（独立进程对照实验定性）。
- **修复**：`load.ts` 重写为主上下文 `new Function` 求值（参数遮蔽浏览器 stub，
  this=globalThis；命名空间落进程全局，无命名冲突）。node:vm 本非安全边界，
  被求值文件不变（SHA-256 溯源），安全姿态不变。
- **实测**：bonus_2 单步 28.80 → 2.43ms（−91.5%，6.8 倍 60Hz 实时余量，慢动作问题消失）；
  48 关均值 0.676 → 0.065ms；单测 22.7s → 4.5s。
- **位级一致**：新增 `benchmark/perf-determinism.mjs`（48 关 × 双输入模式 × 每步全刚体
  f64 位哈希链）修复前后逐关一致；fidelity 84.31 → 84.31。

## R2 · 快照路径（量化后确认已最优）

Colyseus setter 对相同值短路（源码直证）；实测 sync+encode 占 tick ≤2%（最重关），
patch 字节反映真实运动。不做投机改写，数据入档。

## R3 · 客户端加载（−30% 冷启动传输 / reload 近零）

- 音频懒装载：Menu 只装 bgm_menu，游戏 18 键 2.8MB 移入 GameScene.preload（新 audio.ts）；
- 静态服务 brotli 协商（q5）+ `Vary: Accept-Encoding`；
- 分级缓存：哈希产物 immutable 1 年 / html no-cache / 素材 1 天；
- vite manualChunks：phaser/colyseus 独立块，业务更新仅重传 19KB gzip。
- 实测：冷启动传输 6909 → 4858KB；reload 408KB → 3KB、Menu 激活 807 → 570ms。

## R4 · 装载/内存验证

建房 8-21ms、重开 8-13ms；bonus_2 50 仿真秒 GC 摊销 0.02ms/步、堆稳定；
双人 60s 浸泡 60fps、heap Δ0.39MB。无需改动，归档。
