## r15 移植（服务端传输面两件，融合 main #33/#45 演化）
- **staticGz 条件校验**：压缩响应按 编码+mtime+size 生成强 ETag 并带 Last-Modified；If-None-Match（W/ 弱比较、多标签、`*`）与 If-Modified-Since 命中即 304 无正文——新鲜期（1 天）过后不再整份重下；压缩产物失效判据 mtime→mtime+size。#33 穿越防护与 #45 方法闸门原样保留。
- **jsonRes.ts**：/api/levels 与 /api/level/:id 改协商压缩（br q5/gzip6，≥1KB 且压小才压）+ 内容寻址 ETag（sha256）；缓存策略沿用 #45 裁定的 `public, max-age=300`，过期条件复验 304。压缩产物不缓存（单关 ≈1ms，不留无界缓冲）。
- 实测（本地真服 curl）：forest_01 16,995→1,569B（**−91%**）、ice_02 8,952→1,412B（−85%）、light_30 5,814→698B（−88%），If-None-Match 复验全 304；静态图集 JSON gzip 12,551→1,107B 且 ETag/304 生效。
