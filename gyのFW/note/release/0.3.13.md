## 新增

- **暂停**：P 键或画布右上暂停钮 → 「已暂停」面板（重玩/返回菜单/继续游戏）；本地停手语义
  （服务端继续，联机对齐 AFK）。
- **通关面板**：双门到位自动弹出——三行 FinishCounter（通关/钻石/限时）逐行达成（700ms 时序）+
  FinishStone 星动画（1-3 星）+ Continue 回选关；星级 = 1 基础 + 钻石收满 + 限时（原版公式）。
- **失败面板**：化烟后自动弹出——Game Over + 返回菜单/重玩本关。
