# 0.3.25 — 机关碰撞体/贴图一致性专项（拉杆审计九连修复）

起因：实玩发现拉杆碰撞体积与图画不一致。双代理并行审计 14 机关族 + 字节级取证，修复九项，结案档案 `note/research/2026-10-fidelity/12-mech-collider-audit.md`（含「源码在为什么还会错」五根因分析）。

- **拉杆**：贴图角与碰撞体镜像分离——快照角误取负（ba34080；中间误修已回滚 c731ddf）。
- **推杆**：碰撞体恢复原版梯形（0.3.6 误转写 T 形唇；0.1 切角/密度/力一并按 bundle 字证复位，08c0e60）。
- **吊挂/滑轮/罗马杆**：内核有体但快照从不下发，客户端整族隐形——补 MapSchema 与同步（033e7a9）。
- **竖直平台**：贴图换轴排布/帽缩放对齐原版，像素对位 ≤1px（6b2532f）。
- **风机**：机身/风柱贴图弃 rect 中心改 windBodyPos 体心定位，两端同源，偏移 (−80,+16)px 归零（9a71337）。
- **window 结案**：窗框帧在原版全部已发行图集中不存在（缺帧渲染空白）——不渲染才是忠实，实为隐形墙（3def7fc）。
- **P0 平台体角双旋转**：`shapeRotation(−π/2)` 同时烧进体角与 fixture，两次叠加 ≡ 横放——全部竖直平台/转臂碰撞体躺倒 96×28（原版竖立 28×96）、转臂摆位镜像。修复：体角=0（原版 `SetAngle(rotation)`）、n 只进 fixture；客户端重构为原版同构两级容器；转臂关节序按 bundle 复位。多边形转储铁证：forest_07 五臂竖立@槽位、拉动后 0→−90° 摆成横桥，forest_02 竖台满行程 128px（e8463b6）。
- **平台灯罩 + 球首帧**：灯罩 state 进快照随组信号换 light_on/off 帧；球贴图首帧对齐体心 (−16,+20.8)px 不再闪跳（5d01513）。
