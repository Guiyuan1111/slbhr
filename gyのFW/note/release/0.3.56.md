# 0.3.56——r13 地面缓存 + r20 弱网量具 + P0：CSP×seedrandom 断链修复

并行性能线吸收批四（带审核）。本批意外收获一枚潜伏五版的 P0——r13 的浏览器实弹验证抓出来的，修复与门禁补齐同批落地。

## P0 修复：CSP 禁 eval × seedrandom new Function（0.3.51–0.3.55 浏览器建房全断）
- **根因**：vendor/seedrandom.ts 以字符串内联 + `new Function` 注入 AMD shim 加载官方 init.js 提取体；0.3.51 起 CSP（#45）禁 eval → GameScene.create 的 decorate z() 步进抛 EvalError → 场景永停 CREATING。**浏览器建房→Game 全断五个版本**。
- **为什么没人发现**：node 侧 e2e（route-node/servers-smoke）不加载浏览器 bundle；audiofamily 只测装载面不建房。浏览器建房路径此前零门禁——本批补 `scripts/e2e/browser-room.mjs` 并入 CI（建房→Game active pageerror=0 → groundTex 在场 → 离房释放）。
- **修复**：官方 2717 字节改以真实源码模块 seedrandom.umd.ts 入编译图（字节级零改动；define 改参数、module/require var 遮蔽让打包器不误解析）。等值证据：旧路径 vs 新路径 10000 步序列逐数全等、parity 单测 8 锚值、det r0-baseline forest 48 关位级一致。

## r13：地面合成缓存 LRU + 结算期预烘 + 离房释放（qoder 件，审核适配）
- scenes/groundCache.ts：整关地面 canvas 字节账 LRU（24MB≈4 关），「正绑定绝不逐出/当前张绝不逐出」不变量单测钉死；buildGround 收敛「取/烘/绑」三步（合成管线逐字节不动），bound 跳过重绑省 ≈5MB 全幅重传。
- 结算入口（openEndMenu，正常 won 与重连补结算共用）后 500ms 预取预烘下一关；离房 releaseGrounds（摘 game 级纹理+清位图账）。
- 验证：单测 6 例；浏览器实测建房→Game 669ms、离房后纹理释放+Temple active。

## r20：perf-load 弱网档位量具（qoder 件）
- `--net off/cable/4g/fast3g/slow3g`（CDP Network.emulateNetworkConditions），off 档完全不建 CDP 会话、历轮口径逐字不动；waitScale 随档放大等待超时；meta.net 落快照、--compare 档位不同打 ⚠。
- 生效自检移植 qoder r30 教训：Resource Timing TTFB 测不到延迟档（首版自检实弹抓出假阴性）——改页内墙钟直测 ≥0.5×rtt；带宽档看最大单笔响应体耗时。fast3g 实测 Menu 21.4s（off 510ms）、建房 8.3s，自检 PASS。
