# 0.3.22 · M2 触屏虚拟按键（移动端适配第一步）

> 2026-10-08。PLAN §5.4/M2：触屏三键 + iOS 假全屏；自动化触摸 e2e 全过。
> 樱花穿透注册/真机联调仍为 [人工] 项（见 handoff）。

## 新增

- **TouchControls**（`packages/client/src/touch.ts`）：左下（◀ ▶）右下（▲ 跳）三键，
  Pointer Events + setPointerCapture（滑出按钮抬起仍回收），多点同按；
  touch-action:none + touchstart preventDefault + 双击缩放/长按菜单全拦。
- **同源合并**：TouchLeft/TouchRight/TouchUp 三个合成码注入 KeyboardInput 的同一
  pressed 集——变化即发/15Hz 重发/seq/暂停清键语义零改动继承（协议零变化）。
- **可见性**：粗指针设备或 `?touch=1`（桌面调试）才创建；ready 起显示、非进行阶段隐藏
  （与键盘暂停闸门同源，main.ts updateHud 驱动）；DOM 覆盖层不进画布，视觉复刻零影响。
- **iOS 假全屏**：`100dvh`（@supports fallback 100%）——地址栏收缩不再露底（PLAN §9）。
- 顺手修复：返场重进时旧 KeyboardInput 的监听与 15Hz 重发定时器残留（enterGame 先 destroy）。

## 验证（scripts/e2e/touch.mjs，iPhone 设备描述符）

- started 阶段三键可见；真实 touchscreen.tap 跳跃键 → Δy=53.7px；
  按住右键 1.5s → Δx=344.6px（服务端权威位移）；抬起高亮消除；
  桌面 context 不创建按钮；零页面错误。
- 回归：83/83 单测 · typecheck · 标准 e2e PASS（0 错误）· 视觉 94.61（与 0.3.21 持平）。
