## 服务端输入队列（真实服务端精确复现内核时序的前提）

- 输入消息按**到达墙钟戳**入队，每步按意图跨度排水（`deadline = startedWall + stepIndex·STEP_MS + 4`）——
  彻底解耦 Windows 定时器唤醒抖动（实测 setInterval(4) 均值 16.8ms、抖动 ±5ms）与唤醒相位 φ，
  消除「currentInputs 活变量 + 唤醒时步进」模型的 ±1f 抢帧（同帧多事件被两步各吃一次/提前一步抢帧）。
- 新增 `[phase] ready/started @墙钟` 日志（纯观测，回放零点权威锚）。
