# 0.3.3 · 动画/碰撞/声音/手感集中修复（实玩反馈第三批）

> 2026-10-05。用户实玩反馈：拉杆贴图与碰撞错位、跑动动画定格、无声、操作阻尼感。

## 拉杆（用户报告：贴图与碰撞错位）

- **支点修正**：原版用 `GetWorldCenter()−0.7m`（质心=fixture 中心，在 origin 上 0.55m → 支点在图块中心下仅 4.8px）；我们误用 origin−0.7m（低 17.6px）。
- **关节参数序对齐**：原版 `Initialize(杆, 地面)` → 关节角=−杆角，翻转条件/马达方向随之自洽（正侧=state0/负侧=state1，马达压向所在侧限位）；我们此前反序被迫用"过零边沿"近似——本轮回归原版条件直译，删除 hack。
- **贴图锚点修正**：杆/杆灯贴图中心=body origin（原版 resSprite 位置，支点上 4.8px）；此前放在 fixture 中心（高 17.6px）——这就是"贴图与碰撞错位"。

## 跑动动画定格（用户报告：头部起跑半秒后定格）

- **头部跳跃动画循环**：原版 5 个角色动画全部 `!0` 循环；我们 `_jump` 注册 repeat=0（11 帧 ≈0.37s 后定格）——时间与用户描述精确吻合。
- **腿部门槛移除**：原版 head=jumping 即播 legs running（含贴墙推/空中）；我们加了 |vx|>20 近似门槛，已删。

## 声音（用户报告：无声）

- **根因**：Phaser loader 对无扩展名 URL 推断不出音频类型，**入队即跳过**——12 个音效自 0.2.0 起从未加载（playwright 实测：零音频请求、缓存为空）。
- **修复**：`load.audio` 改对象形式 `[{url, type:"mp3"}]` 显式声明类型；保留无扩展名路由（防 IDM）。实测 12 项全部入缓存、网络请求正常。

## 手感（用户报告：阻尼感）

- 插值改造：纯指数平滑（20Hz 快照阶梯+低收敛率=持续滞后）→ **速度外推（dead reckoning）+高收敛率**（本机 40/s+50ms 前推，对方 20/s+25ms）。
