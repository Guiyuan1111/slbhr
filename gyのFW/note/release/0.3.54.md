# 0.3.54——并行性能线吸收批二（r16 三族移植 + r14 件，带审核）

延续 0.3.53 的收容分流，本批按"审核→适配→验证"吸收 qoder 战役的客户端传输件。游戏行为零改动（播放侧键选择本就三分支，本批只收口装载面）。

## r16：BGM 按关卡类型选族（审核后扩三族）
- **审核发现**：qoder 原版两族（general/speed）建立在"森林无 dark"前提上——main 的 light 部有 7 个 dark 关（142 关分布 general 69/puzzle 41/speed 25/dark 7），前提已过时。移植设计改为 **general/speed/dark 三族**，DARK 族终局曲与 general 共用（对齐 oracle preloadAudioFiles 与 GameScene.finishKey 的 else 分支：speed 才换 finish，dark 不换）。
- 装载面：AUDIO_GAME 拆为 SFX（18 支，三庙机关声恒取）+ 失败曲 + 本族 BGM；BootScene 暖装按族预判（main.ts 深链 ?level= 经 temple.json 单例预判写入）；GameScene.preload 按本关 templeEntry.type 兜底补齐（init 先于 preload，type 同步可得）；播放路径缺键已有 cache.audio.exists 门禁。
- 额度（磁盘实测）：general/puzzle 关省 646.5KB、speed 关省 1919.2KB、dark 关省 1620.9KB——此前每关全量装 2,309,067B 六支 BGM。
- 验证：纯函数单测 7 例（族映射与 bgmKey/finishKey 同式、三族清单、sfx 恒取）；新浏览器装载面门禁 `scripts/e2e/audiofamily.mjs` 3/3（speed 深链/dark 深链/无深链各只装本族，本地实测过；dark 例为三庙适配新增，qoder 原版没有）。
