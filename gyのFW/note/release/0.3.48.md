## P0/P1 安全与服务端

- **#28（P0）** 房间密码无条件校验：密码校验原在实例 onAuth（被框架忽略）且 onJoin 按 options 类型判断调用——`joinById(roomId, true)` 布尔 true 可整体绕过。改 onJoin 首行 `assertPassword` 无条件校验，true/缺参一律 4403；断线重连走 isWaitingReconnection 分支不经 onJoin，座位恢复不受影响。回归 4 例含重连路径。
- **#21（P1）** 限流加固：key 缺省只取 TCP 对端地址（X-Forwarded-For/x-real-ip 可伪造，Colyseus context.ip 优先采信它们=无限换桶绕过）；`FW_TRUST_PROXY=1` 才采信且要求 isIP 合法。authWindows 有界化：热路径 O(1)、惰性清扫每窗口至多一次、硬限 4096 桶淘汰最旧（均摊 O(1)）——伪造 IP 洪水的 O(n²) CPU 放大与内存无界双堵。
- **#32（P2）** matchmake 非 POST 405（带 Allow 头）+ HTTP server 超时兜底（headers 15s/request 30s/socket 60s）。
