# forest_32_1 摆渡人死锁：唯一升台通道 160px 墙 + 压钮/登台异地 → WIN 不可达（双引擎封关档）

日期：2026-10-12（r32d 会话，接 forest_32 v10 通关档）。结论先行：**forest_32_1 在原版数据与双引擎（内核 + 原版 oracle）行为下不可通关**——路线 A-F 相位全部可解（含镜像渡河），但终局陷入"摆渡人死锁"：唯一离地通道 obj13 平台升至 704（dy=5），从西岸 864 登台需 160px 升幅，双引擎实测最大跳升 95.9~126.6px；而平台唯一控制源（按钮）位于 1000px 外的东坑底，压钮者永远无法在 95f 可登窗口内赶到西岸。地位等同 14 号档（03_1）/15 号档（21）/18 号档（11）/21 号档（28）/22 号档（09）的"生成缺陷关卡嫌疑"，交由用户决策。

## 3. 核心闸门一：160px 登台墙（probe14 T1 + oracle O1）

登台 = 从西岸(脚 863.7)跳上平台顶 704，需升幅 **160px**。内核配方扫描（平台升满态）：

| 配方 | 起点 | 最高点 | 升幅 | 距台顶差 |
|---|---|---|---|---|
| 岸上满持跳 25f @150 | (150,863.7) | (133,789.8) | 73.9px* | 85.8px |
| 岸上满持跳 25f @200 | (200,863.7) | (141,737.1) | **126.6px（全场最大）** | **33.4px** |
| 岸东缘 @280 | (280,863.7) | (251,773.0) | 90.8px | 69.0px |
| 水面起跳 @300 | (304,869.5) | (259,763.7) | 105.8px | 59.7px |
| 助跑 30f + 满持跳 | (200,863.7) | (54,790.0) | 73.8px* | 86.0px |

\* 升幅被截原因：平台升满后其本体 [32,128]×[704,736] 悬于井口，弧线漂入板跨即被板底钉在脚 ≈793（头 733.8 触底 736）；@150/@108/助跑 各组皆此截顶。干净弧（理论 v²/2g = 123px，16 号档 oracle 口径 118.9px）最多 126.6px，**全场景无一配方达到 160px，最好差 33.4px**。
墙助不适用：平台升满后其东脸（x=128, y[704,736]）悬于岸上玩家头顶 130px+，无法贴脸；平台正下方 x[96,128) 无立足地（空洞）。
oracle O1（出生注入西岸中心 200，f80 起 W 按住 25f）：rest (200,863.74) → apex (189.89,767.8) = **升幅 95.9px，距 704 差 63.8px**；叠加 16 号档干净弹道上限 118.9px 口径仍差 ≥41.1px。**双引擎一致：160px 不可达。**

## 4. 核心闸门二：压钮/登台异地 → 中途接应窗口（probe14 T2/T5 + probe13 G 实测）

- 平台升程：内核 864→704 用 **147f（1.088px/f）**；oracle O2c **149-151f**。可登窗口 = 顶从 864 升至 761（最后可跳及高度）≈ **95f**（两引擎同量级）。
- 箱平底滑行（T5，台面 856）：推 60f 松手滑行 **≤2px**；推 120f 松手 **≤1px**——**压钮必须贴箱连续推到钮区**，无"提前松手让箱自滑"的提前量。
- 球（T4）：从坑坡顶(995,840) 连推 10f/30f，滚至 (1076,883) **停住，差按钮西缘 44px，永不触钮**。
- 冲刺实测（probe13 G）：wg 从按钮位 (1142,895.7) 经 b坡出坑→台面→涉水西渡到跳点 (146,863.7) 用时 **258f ≫ 95f**。
- 结论：**按压钮瞬间压钮者必在东坑底，距登台点 ~1000px；任何"压完再跑"都错过可登窗口 ≥160f**。

## 7. 判定

- forest_32_1 原版数据下 **WIN（双门同时 isUp）不可达**：fb 可达火门、wg 永困地面层（或镜像变体 fb 困东岸），双门条件永不同时满足。
- 缺陷定位：obj13 `dy: 5`（32 为 3）。dy=3 时升程 96px 可跳（32 号档 G 相位 96 跳实证），压钮者可自行追平台上台；dy=5 使唯一通道超过跳跃上限 33~64px，触发摆渡人结构死锁。**单字段生成缺陷嫌疑**（与 03_1/11/21/28/09 同类），按封关范式呈报，不改动关卡数据。
- 工具与原始输出：`TEMP/r32/probe13.mjs`（镜像装配）、`TEMP/r32/probe14.mjs`（T1/T2/T4/T5 电池）、`TEMP/r32/ora1.mjs` + `ora1-*-trace.json`（oracle 三探）。
- 本档不向 scripts/e2e/inputs/routes/ 发布 _1 路线（WIN 不可达，无从产线）。
