## §1 基座机制（与 forest 同源，我方 kernel 已移植同款）

- **Device**（@1618057）：`state = +properties.initialState || 0`；rotation deg→rad（`(π·deg)/180`）；
  **pxm/mpx 取负**（原版 y 翻转口径）；`registerDevice`→MechManager + group 登记；
  group 色=组号首位数字（groupColors 1..7）。
- **BoxedDevice**（@1623524）：boxSize 缺省 2×2（米）；body 按 rotation 预偏移中心（`(w/2,h/2)` 旋转 deg→rad，
  x+=e.x, y−=e.y——**Y 取负**）；`ocupy` 占 4 tile。
- **MechManager**（@1833897）：`deviceChanged(device)`：组内**signal 设备 state OR**（`g = g || b.state`）→
  非 signal 设备 `state = g` + 全组 `_updateState()`（updateLight + updateState）——与我方 kernel MechManager 同构。
  创建序=Tiled Objects 层对象序（createObjects 逐对象 new，顺序即帧序）。

## §2 Beamer（发光器，extends BoxedDevice）

- options：`pusherWidth 0.8, pusherHeight 0.4, frame beamer0000`；state 恒 1；body.mass=0。
- 附加碰撞多边形（本地米坐标）：`(0,−w/2−0.6)(0,w/2+0.6)(−h,w/2)(−h,−w/2)`——向 −x 伸出的实体座。
- 光束：`update()` 每 RayCast 段循环（≤11 段）：原点 `(options.x, options.y)`（米），
  **方向 = rotate((−1,0), rotation)**——本地朝 −x、随 rotation 转；步进 = point+dir×50m。
- 命中分类（RayCastCallback 按 fixture.userData.lightProperties）：
  - 无 lightProperties → 不透明：记录命中点，dir=null 停束；
  - `type:"transparent"` → 穿透（回调返回 undefined 继续）；
  - `type:"normal"` → 不透明停束；若 `sensor:true` → 标记 `iluminated=color` + `lightAt=命中点`；
  - `type:"mirror"` → 反射（入射向 b=normalize(起点−终点)，法线 n，`f = n × 1`（CrossVS 标量叉），
    `dir = b − f·2(b·f)`）；sensor 同样标记；
  - `type:"portal"` → state=1 时传送（skipPoint+output(dir)），state=0 穿透。
- 颜色：`properties.color`：blue=#AAEAFF / red=#FF4D00 / 缺省 #ffff88。
- 渲染（客户端）：LIGHTEN 混合三层线宽 [30,10,2]/α[0.05,0.3,1]（实际画 d=1,2 两层：10/0.3 + 2/1）。

## §3 RotMirror（旋转镜，extends BoxedDevice，**物理体+revolute**）

- options：`boxWidth 1.8, boxHeight 1.8, mirrorWidth 2, mirrorHeight 0.1`。
- fixtures：①盒 1.8×1.8 **transparent**（角色可站/推）；②镜条 2×0.1 **转 45°**（SetAsOrientedBox π/4）
  `type:"mirror"` density 0.2；③④两个 r=0.25 圆帽 @`(±(boxWidth/2−0.25), ±同)`（角色站踏旋转的踏点）。
- revolute 钳位：`dir===1 → limits [−rot, −rot+π/2]；否则 [−rot−π/2, −rot]`；enableLimit；motor 恒开
  maxMotorTorque 100；`updateState`：state=0 → motorSpeed=−1.5·dir，state=1 → +1.5·dir（**group 0/1 控制换向**，
  与 pusher/lever 同 machinery）；初始角=对应 limit；update 每帧钳角（越限即钉）。
- properties：`dir`(1/−1)、`bringToBack`（渲染层）。

## §4 BoxMirror（箱镜，extends BoxPrototype→BoxedDevice）

- `mirrorWidth 2, mirrorHeight 0.05, frameName BoxMirror0000`；**动态可推箱**（BoxPrototype 语义）；
  箱体 fixture 改 `type:"transparent"`；另加 45° 镜条 fixture（2×0.05，π/4）`type:"mirror"` density 0。

## §5 InfiniteMirror（无限镜，extends BoxedDevice，**受控角**）

- options：`boxWidth 1.8, boxHeight 1.8, mirrorWidth 3, mirrorHeight 0.1`；无 transparent 盒（仅镜条+r=0.3 双帽 @±1.1）。
- revolute 至地面：enableLimit+motor（torque 500，speed 0）；`updateState：joint.SetLimits(state, state)`——
  **state=连续角**（来自 slider 的 π·t·max/width 或 lever 0/1）；初始 SetAngle(rotation)。

## §6 LightPusher（光控推杆，extends BoxedDevice）

- options：`pusherWidth 1, pusherHeight 0.4, sensorWidth 1.5, frame lightpusher_base0000, light lightpusher_light`。
- fixtures：①**sensor**（1.5×0.4，isSensor）`type:"normal", sensor:true`——接受光束照射标记；
  ②梯形实体座（w±0.5，h−0.1）`type:"transparent"`。
- `checkState`：`state===0 && sensor.iluminated === properties.color → state=1 + signal.dispatch`；
  `state===1 && iluminated !== color → state=0 + dispatch`；随后 `sensor.iluminated = null`（每帧清）。
  ——**即照即开、光断即关**；经 group 派发开窗/门等。

## §7 Slider（滑轨电位器，extends Device，**prismatic**）

- 数据：非 gid 对象 `type:"slider"`，polyline 两点（水平轨宽 o=polyline[1][0]−polyline[0][0]），properties.group/max。
- 本体：r=0.3 圆（friction 0）+ SliderDot/SliderTrack 贴图；**prismatic joint** 轴 (−1,0)，
  `upperTranslation=−pxm(o/2), lowerTranslation=+pxm(o/2)`（**注意负号约定**），maxMotorForce 20，linearDamping 1。
- `checkState`：`state = π·jointTranslation·(properties.max||1) / pxm(−o)` → 连续信号派发全组
  （InfiniteMirror 的 SetLimits 直接吃它）；translation 跨 1/27 格响一声（音频侧）。

## §8 光束×世界交互面（谁挡/谁穿/谁被照）

- **不透明**（无 lightProperties）：全部地形/角色/普通箱/门等——挡束。
- **transparent**：Beamer 座外沿?（否——beamer 座无 lp 即不透明）、RotMirror 盒体、BoxMirror 箱体、
  LightPusher 梯形座、BoxPrototype(普通箱 portal 用)——**角色可穿束而过的机关体**。
- **sensor:true**：LightPusher sensor、Liquid 表面 sensor（下条）。Beamer 照到即标记 iluminated。
- **mirror**：RotMirror/BoxMirror/InfiniteMirror 镜条；**冻结后的液面也变 mirror**（initialFreeze 里
  `sensorFixture.lightProperties.type = "mirror"`）。

## §9 光束×液体（重大机制：冻桥/融冰）

- Liquid（@1660421）持有 surface `sensorFixture`（lightProperties sensor）。`update` 内检查：
  `iluminated==="blue" && type===5(水) → shouldFreeze()`；`iluminated==="red" && type===5 → shouldMelt()`。
  非 type 5 不反应。绿浆(7)不参与。
- **freeze/initialFreeze**：frozen=true；iceFixture filter={maskBits:16, categoryBits:1}（冰面仅与角色层碰撞）；
  nearBodies 逐个：角色 → 位置上移 0.5m+SetAwake；其他动态体（箱）→ **转 static**（冻在原地）；
  `sensorFixture.lightProperties.type="mirror"`（冻面反光）；iceGraphics 显/liquidGraphics 隐。
  initialFreeze 额外先跑一步未暂停物理（装箱 settle）。b=800（动画 ms，客户端）。
- **melt**：逆操作（frozenBodies 回 dynamic、type 回 normal、图形互换）。
- nearBodies 采集：液面 AABB 查询（待反解具体范围，实现时对照）。
- light 部地表 gid 直方图：solid 12109/斜 643/楔 671+533/**水 512/岩浆 184/绿 167/冰 304**（gid8=冰砖）。
  我方 GROUND_TYPE 无 8——需增 ICE + 冻结态改 type 的解析支持。

## 附：帧序结论（确定性关键）

每帧：Phaser box2d world.step（体序=创建序）→ 各设备 sprite.update（设备创建序=Tiled 对象序）：
Beamer.update（raycast 标记 illumination）→ LightPusher.checkState（消费标记→state 派发）→
RotMirror.update（钳角）→ Liquid.update（查标记冻/融）→ Slider.checkState（连续 state 派发）→
InfiniteMirror.updateState（SetLimits）——**顺序=对象创建序逐设备**，我方 kernel 按同序步进即可复刻。
