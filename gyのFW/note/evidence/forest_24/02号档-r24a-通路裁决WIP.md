## 1. 静态裁决（代码级 + 地形复核）

- **跳跃语义（character.ts L222-230）**: 起跳 `SetLinearVelocity(v)` **绝对赋值**——平台/杆体速度不叠加，弹射增益不存在（蓝图 §6.3"杆上弹跳"探针题在代码级已否定）。v=(当前vx, 15.5)（平地 n.y>0.65），若 len>15.5 整向量缩到 15.5 → **任何水平速度都压低跳跃高度**，静止满跳=唯一最大值。
- **檐台墙**: fb 门传感带 (1134-1198, 672-680)，站台需 C≤636.8。r1 翻转后东顶尖 (1086,825.4)，fb 立顶尖实测满跳 apex C=673.6（[R2]）→ **差 36.8px**（理论 30px + 站位损耗）。檐台上方竖井 x1120-1216 y544-672 仅西侧开放——檐台唯一进入=西侧空中横越。
- **下井墙**: 上腔→下腔唯一通道=中央地板缺口 x64-160（r16 实测 x160-1248 全实心，蓝图 §4"东井竖缝直落檐台"系误读——东井 x1152-1216 底部被 r16 封死，井=死端（2 蓝钻））。按钮 pusher(1152,512) 距缺口 1040px；释放后窗口≈ t 回弹 30-60f + 平台回程 90f ≈ **150f**；玩家极速 4.53px/f → 跑程需 230f+。**单人无法既踩钮又下井（与蓝图 §6.1 一致），且第二人无法跟进——除非按钮被持续压住**。

### 5.3 根因（bundle 代数）

原版 `d12-roman.txt @1748970`: `h = (options.x + poly[1].x + mpx(1), options.y + poly[1].y − mpx(1))`，其中 `options.x/y = Tiled 位 + (32,−32)`（dump 实证 optsXY=(656,480) vs Tiled (624,512)），`mpx(1)=−32` → **±32 相消，h = 折线顶点绝对坐标 p1 本身**（r0: (624,448) ✓ 实证）。BASE 同式 = h+(0,+32k)。

本内核 mechanisms.ts buildRoman L527 `h = p1 + (−32,+32)` —— 把 options 空间偏移**重复计入**（level2.ts absPoints 给的是 Tiled 绝对坐标，未含 options 居中）→ 全部 Roman 平移 (−32,+32)，枢轴低 32px、底座半埋地板、静息角 7.43° vs 18.17°，杆西尖净空 62px vs 140px → 箱死 vs 箱过。

**影响面**: 全库仅 forest_14/14_1/24/24_1 含 roman。修复=mechanisms.ts L527 改 `h = {x: p1.x, y: p1.y}`（base 公式不变，随 h 自正）。forest_14 既有路线需中央复核。
