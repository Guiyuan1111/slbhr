### 3.1 旋转平台 p0/p1（dtheta=90 / offsetY=−1.5，27 号档同型）

- **f0 形制（probe B/geo b8/b9 直证）**：竖直板墙 28.2×128px，p0 = x[1025.9,1054.1] y[472,600]（体心 (1040,536)）、p1 = x[1025.9,1054.1] y[608,736]（体心 (1040,672)）；两墙上下邻接（y600/y608 间 8px 缝）组成 x≈1040 的竖直栅栏，把东中腔分为西室（x960-1026）与东室（x1054-1216）。p0 顶 8px 插入 r14 箱台底缘（y448-480）、p1 悬于东大块底 y608 之下——**旋转扫掠全程穿地形无阻滞（25 号档幽灵穿透口径，probe C 实测 ja 顶格 90.9°）**。
- **枢轴**：体心上方 48px（offsetY=−1.5）→ p0 (1040,488)、p1 (1040,624)。
- **ON 运动（probe C/D 实测）**：压下推块（b0 首帧 t=0.178、f2 state=1）→ 平台马达 ±2rad/s → **屏幕逆时针转 90°**（ja 0→90.9° 含 0.9° 扭矩挠曲，约 60f）→ 终位**水平搁板东伸**：
  - p0 → x[1023.8,1152.2] y[472.1,502.3]（体心 (1088,487.2)）——顶面 y472 插入 r14 箱台（y448-480）内 8px，**可行段仅东伸部分 x1120-1152**（箱台以东，顶 472.1）；
  - p1 → x[1023.8,1152.2] y[608.1,638.3]（体心 (1088,623.2)）——顶面 608.1 紧贴东大块底 y608（0.1px 隙），**整条搁板无头部净空，行走价值存疑（§6.3 骑角候选）**，其语义主要是**把竖墙收走**。
- **OFF 回程**：离手推块马达 −15 约 20f 内 t→0 → 组信号归 0 → 平台原路转回竖直（probe C：回程 60f，残存体角 0.86° ≈ 1px 偏斜，下压再 ON 复位）。
- **probe B/C 真实输入链实证**：fb 传送站上 b0 顶面（y396.8）→ 体重大于马达 5N 保持力 → 推块下沉 t 0→0.607 钳制 → state=1 → p0 转 ON；fb 随推块下沉 24px 稳站 (480,380.5)。b1 同构（fb 稳态 (592,444.5)，p1 ja=91.0°）。**站上即触发、离手即回弹**——与杠杆的持续态不同，时序窗口 = 站立时长 + 回程 60f。

### 3.2 平移平台 p2（g3 闸门；level2 语义 ON 位移 = −32·(dx,dy)）

- **f0 形制（probe B/geo b7 直证）**：竖直板 28.2×128px x[353.9,382.1] y[768,896]——恰好**满高堵塞 c10 柱（x320-352）与 c12 柱（x384-448）之间的 32px 底层通道**，板底立主底板 y896。
- **ON（l0 扳 ON，probe E 实测）**：升 128px → x[353.9,382.1] y[640,768]（体心 832→704；速度 64px/s 约 150-200f 带缓停，on+f150 到位）——**打开底层 x352-384 通道**（西底腔 ↔ 东底段 x448-608，主底板 y896 上的地面级通口）。板升起后其顶面 y640 与 r19 西中板底 y640 齐平封住竖槽上口。
- **OFF（l0 扳回）**：原路降回 f0（off+f150 精确回位 y[768,896]）。
- **闸口静态通行（probe F 实测）**：p2-ON 后 fb 传送入缝 (368,860) **稳定站立 150f 不动不楔死**——角色 28.8px 宽 vs 32px 缝（每侧 1.6px）静态可行；动态走入/骑角未测（§6.3）。
