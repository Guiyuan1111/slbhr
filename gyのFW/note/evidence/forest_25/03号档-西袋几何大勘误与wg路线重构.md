# 03号档——西袋几何大勘误与 wg 路线重构（r25d）

日期：2026-10-15。槽：r25d（forest_25 生产）。内核：907ba54 之后（det 基线 r32）。
方法：`gb.GetFixtureList()` 逐 fixture 顶点 px 坐标直读（TEMP/r25d 多个 dump 片段）+ p13 系列相位机实测。
**本文推翻 01/02号档中 wg 西行路线的三个关键假设。**

## 1. 全高墙（288-320）——01/02号档未记载的封死结构

x288-320 从天花板(y32)直通 r8(256) 再经 ledge 柱(x288-352, y288-448) 直到带面(448)。
fixture 顶点（摘要）：`(288,64)-(320,32)`、`(288,96)-(320,64)`、…、`(288,256)-(320,224)`、
r8 条带 `(192,256)-(320,288)`、ledge 条带 `(288,288)-(352,320)`、`(288,320)-(352,352)`、
`(288,352)-(320,384)`、`(288,384)-(320,416)`、`(288,416)-(320,448)`（楔）。
**结论：东部（出生台/走廊/池/塔/ledge/柱/带东段）与西部口袋（带西/tier/竖井/r8/坡/平顶/b0）在带面以上完全隔离。**

实测后果（p13 trace）：
- 塔顶 (465,224) 起跳无论高度（apex feet 99）横穿 x335.4 即 vx 归零（身体圆贴墙面），回落。
- ledge(288) 西向同理（贴墙 335.4 站位即墙效应，v=(0,0) 永卡）。
- 02号档 §6.4 v3 配方"横带西行→楔尖(192,448) 三级爬升"的前半段（横带西行）不可达，见 §2。

## 2. 横带西行封死——楼梯台阶（416/384/352 三级 32px 台阶+45° 斜肩）

带东段 (440-576) 西行在 x431.6 永卡（身体圆 r15.4 顶 416 立面）。结构（fixture 顶点）：
- rect (384-416, 416-448) 顶 416
- rect (352-416, 384-416) 顶 384
- rect (352-384, 352-384) 顶 352 + 楔 (320,352)-(352,384) 顶平 352 + 柱 (288-320, 352-384)
即 448→416→384→352 三级台阶，可 32px 跳登（带→416→384→352 已证可达），
但 352 台面（x288-384）西端即全高墙（x288 立面自 y32 落下）——**西行终点=死墙**。

## 3. wg 水池弹射（水上漂）——潜航不可行

入水实测（v=(0,0) 起步全速西行，风 ON）：走廊缘 ~x832（842→796 间落出），
弹道 (832,128)→(633,299) 入水（纯抛体，风无贡献），水中 15 帧内被西壁(544-576,320)弹射起飞，
出射 (575,266) v=(-161,-161)，延续为 A→B→C 旧链的"阶梯弹射"。
浮力 floatForce 30N ≈ 重力 29.6N（净上浮）——**wg 无法下潜**，01号档/02号档"wg 潜过池底缺口入西空腔"类方案全部不可行。

## 4. 西口袋精确实测几何（fixture 顶点，修正 01号档若干坐标）

- tier：**x0-160 平顶 y352**（含 D 楔 (128,384)-(128,352)-(160,352) 顶平段），非"x0-128"。
- r8：**x160-320 平顶 y256**（含 C 楔 (160,256)-(192,256)-(192,288) 顶平段），非"160-320 且西缘 192"。
- 平顶：**x0-128 平顶 y128**（(0,160)-(0,128)-(128,128)-(128,160)），b0 板位 (64-96)。
- '\'坡：(128-160, y128-160)，对角线 (128,128)→(160,160)，SW 实体。
- 带顶：**x192-576**（西楔 (192,448)-(224,448)-(224,480) 顶平段），l0 杆 (496,448) 占 480-512 缺口。
- 竖井：x128-160（y160-352 空腔，坡底面之下）+ x160-192（y288-448+，西侧烟囱，下通 p1/前厅）。
- 岛台：x192-288 顶 y736（(192,736)-(288,768) 一带）；p1 桥 96-192 顶 736；前厅顶棚即三者。

## 5. 唯一可行 wg 路线（v11，复用 fb 东线）

东侧唯一西进口=走廊下降缘 x~832（fb 同款）。wg 与 fb 共用东线（fb 早期链 r25c probe13
已验证至板带 (1143,732)，f973）：

1. 出生台西行走廊 → 缘 x832 缓速垂落 → **mesa (800-1024, 256)**（全速则越入水池）。
2. mesa 东行 → 东降阶梯 → **板带 (992-1248, 顶 768)**（fb 同段）。
3. 板带西行至西缘 (992) → 落 96 → **东岸 (896-1024, 顶 864)**。
4. 岸西缘 (896) 站跳满跳（vy496 全升 124）→ 空中 L → **软着陆 h0 吊板 (637-739, 744)**（fb 同款技术，02号档 §6.4）。
5. 板上泵摆西移 → 板心 x≤497 满速跳 → **岛台顶 (192-288, y736)**（fb 同款，r25d 板段物理已吃透）。
6. **口袋内爬升**（本档 §4 几何）：岛台(736) → D 楔斜 (160-192,608-640) → 608/576/544 台阶西上 →
   (80,544) UR 满跳 → **带西 (192-288,448)** → 刹车 UL 跳 → **tier (0-160,352)** → 东行 UR 竖井跳 →
   **r8 西 (256)** → 西行 UL 短按(4f) → **'\'坡斜面 (~148,128-160)** → 45° 爬 → 平顶(128) → **b0 (80,128) 按住**。
7. [fb 过走廊扳 l1 后] 平顶东行下坡 → r8 西缘 (160,256) → **烟囱直落 x160-192（~480px）** →
   天窗（p1 已西移）→ 前厅 (896) → **wg 门 (176-240)**。

b0 按住 → p0 升 (800→704) → 板带下走廊 (992-1216, y800-896) 打通 → fb 过脊进走廊扳 l1 →
p1 永久西移 → 天窗 (96-192) 敞开。wg 尾段烟囱恰好经天窗入前厅，时序自洽。
