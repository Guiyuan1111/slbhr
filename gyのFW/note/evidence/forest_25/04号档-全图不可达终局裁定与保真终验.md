## 2. 风物理保真终验（oracle bundle 逐字比对）

```js
b = new box2d.b2Vec2(0,1); b = b.SelfRotateRadians(this.options.rotation || 0);
a = d.body.data.GetPosition().SelfSub(this.body.data.GetPosition());   // 只取 GetLength() 做衰减
```
