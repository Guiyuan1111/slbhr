## 2. 风物理保真终验（oracle bundle 逐字比对）

oracle `output/A/js/init.eb02fbdab2aa1d24.js` Wind.prototype.update 反混淆：

```js
b = new box2d.b2Vec2(0,1); b = b.SelfRotateRadians(this.options.rotation || 0);
a = d.body.data.GetPosition().SelfSub(this.body.data.GetPosition());   // 只取 GetLength() 做衰减
b.SelfMul(1.2 + 0.2*Math.sin(game.time.now/1e3)).SelfMul(100).SelfMul(1 - a.GetLength()/length);
d.body.data.ApplyForce(b, (0,0));
// 阻尼：v.SelfMul(基于 elapsed/16.67)，随后限速
```

内核 `packages/shared/src/kernel/mechanisms.ts L658-682` applyForce：dir=(0,1) 旋 body 角 → f=(1.2+0.2·sin(nowS))·100·max(0,1−dist/lengthM) → ApplyForce(dir·f) → v×0.975 + 15m/s 限速。**逐项一致**（dist 只进衰减标量，力向量为固定朝向——与"位移向量直接乘标量"的误读相反，已纠正）。内核无风保真缺陷。
