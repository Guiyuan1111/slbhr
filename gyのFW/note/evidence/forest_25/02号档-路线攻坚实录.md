## 1. 风墙实证（P2 证伪）—— 01号档 §6.2 P2 的最终答案

- mesa 顶步行东行**失速于 x≈936-971**（T2a: 900f 振荡带，永不越过 x971）：风力在 dist<14m 内 49-88N > run 50N（净推力 x>950 转负）。
- **任何跳跃（含失速区起跳）东向位移为负或 ≤+190px，落点极东 x≈971**（T3 全表: F=560-760 起跳全部回落 x943-971；失速区 x943 起跳反而倒退落 x835——低初速→长滞空→风推累积）。
- 跑跳弧顶 body 短暂脱风带（rise 95.5 > 脱带需 89.6px）的"无阻尼窗口"不足以补偿：**风 ON 时 mesa 东斜坡 (x1024)/井口 (x1056) 不可达。P2=FALSE，镜像路线（双角色同走）不存在。**
- 推论链: spawn 唯一下降缘 x832 → 风 ON 落点只有 mesa 西缘/池东壁角/水池（fb 死）→ fb 唯一通路（mesa→井口）被风墙锁死 → **风必须先关**；l0 只能从西侧（横带 y448）够到 → 横带只能从西袋/塔阶/西竖井空腔下来 → 都始于底层西侧 → 底层西侧与东侧只隔绿池（双杀）+水池（杀 fb）→ **唯渡者=wg 落水池（水免疫）**。全图唯一解锁钥匙 = wg 走落出生台全速西缘弹道（01号档 F1/F2 对 fb 的死亡弹道）入池。

## 2. 关键物理事实（内核实测）

- **液体实心带可站**（30号档结论在 25 复现）: wg 落水池 (680.8,298.9)/(632.7,298.9) idle 稳定（feet≈327.7 站液面下实心），且**可带速度行走**（probe5: 池底西行 3.6px/f）。
- **池东壁角骑角稳态**（01号档 §7.1 "H1 悬停"谜底）: 落点 x∈[726,731] 的角色**站定于水池东壁 (736,320) 顶角**（foot circle r6.4 搭角），idle v=0 永稳（K=70-85 全收敛此处）。对 wg 是可选中转，对 fb 是风 OFF 前唯一 Mesa 前阶段（本路线未用）。
- **45° 斜坡行走**: 上坡可行（坡面无墙时）——walk 力坡面投影 29.7N > 重力沿坡 21.9N（净 +7.8N）; **楔形角落（坡面+竖墙夹角）= 死锁点**（v=(0,0) 永卡，竖井 r20\ × c32 东立面碗形陷阱 (1071.6,617.3)）。
- **贴墙/贴角起跳零漂移**: 壁面接触锁死横向漂移（probe7 A1 vs 碗形探针: 干净空中 vx 增益 −16px/s/f = 全量 floatForce 30 m/s²；贴墙则 0）。**空中机动依赖"起跳 preserved 初速 + 空中力"，有墙即废。**
- **空中刹车**: idle i=7·(−vx) 以 k≈13.3/s 指数衰减 → 刹停距离 ≈ v0/13.3（walk 280px/s → 21px）。
- **风状态预置**: `winds[0].state=0` 会被 MechManager 信号同步当帧覆写（wind 是 l0 纯跟随端）；须对 l0 body 施 +30 外扭矩把 ja 翻负（01号档 [G] 同款），state 才稳定 0（probe6 预置段 200f 后 wind=0 恒定）。
- 空跳参数: 站跳 rise 124px（跑跳被 len cap 压到 ~95px）；满跳滞空 ~60f；空中按方向漂移 ≈ 0.1335·T² px（T=按住帧数）。

## 3. 双链配方（反馈式内核已逐段走通；待帧锁定）

### wg 链（风 ON 先行；probe5 大半走通）
1. f90 起全程按左: 全速走落 spawn 西缘 → F1/F2 弹道入池（不死）→ 池底液面带西行

3. 台沿 UR 跳（空中 R 按住 T≈26-33f）→ 落塔三级平顶 (480-544, y288)
4. 西行走落 x480 → 落横带 y448（x352-480 空腔正下方）
5. 东行顶 l0 杆尖 (472.5,415.7) → **风 OFF**（wg 实体扳杆待本档第 3 轮探针验证）
6. 折返西行横带 → 西缘 x192-224 → 落西竖井空腔 → 稳落西壁台 y608（x0-192）

### fb 链（等风 OFF——即 wg 第 5 步之后启动）

4. L 沿 / 阶梯西降 → r17 块顶 (y544, x1120-1152) → x<1148 刹 → 尖步出西缘 → 近垂直 148px 落 **基座东坡 \ (x~1100)** → L 爬上基座平台 y672

6. 西行 x<1022 刹停（~1001，台西缘 x992 前）→ **UL 按 30-45f 跳左**（漂移窗 190-450px 宽）→ 落**吊板 h0 东段**（静止板 x544-832 顶 y740；wg 从不碰板 → 板态确定）
