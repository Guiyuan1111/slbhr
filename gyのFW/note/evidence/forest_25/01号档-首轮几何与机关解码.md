### 3.1 风机 f0（本关核心机关；几何有勘误，务必读本节）

- 机身：体心 screen (1216.02,208.01)，体角 −90.022°（=JSON rot −180.022°+90），喷嘴梯形**实体**夹具 screen (1157-1275, 189-208)（底 118px/顶 80px/厚 19px，非 sensor）。风柱 sensor：`SetAsOrientedBox(1.3, 7, center(0, 7.5))` 随体角旋转（mechanisms.ts L604）。
- **★几何勘误：geo-f25.mjs 打印夹具顶点时未加 body 旋转，输出的"竖直风柱 x[1174,1258] y[−256,192]"是未旋转的局部形状，不是世界形状。真实风柱 = 机身西侧的水平风带：screen x[752,1200]、y[166.4,249.6]（14m 长 × 2.6m 宽）**——即出生台板（y128-160）下方空腔的风道。由 mechanisms.ts L603-609 + 体角 −90.022° 推得，并被 probe2 [H] 行为实证（fb 垂直下落穿 y166-250 带时被阻尼+西推，H1/H2 分岔）。
- 风向/力（applyForce L627-650，state==1 时每帧 pre-Step）：dir = R(−90.022°)·(0,1) = world(1.000,−0.0004) = **屏幕向西**；力 f=(1.2+0.2·sin(nowS))·100·max(0,1−dist/14m)，dist=角色体心到机身中心距离（>448px 归零）；凡 activeRoles 内角色（进出风带由 sensor 回调维护，world.ts L334-338）**不论距离**施加全向阻尼 v×0.975/帧 + 15m/s 限速。
- **f0 初始态实测（本档核心结论）**：瞬时 0 state=0；首帧 checkState 判 `state==0 && ja×onis<0`：(+36°)×(−1)<0 成立 → **state=1，风机从第 1 帧起 ON**（probe A：step1 后 l0 state=1/wind=1，ja 仅 36→30.7→37.0 微摆；probe B：240f idle wind 恒 1）。视觉上拉杆从未动过——自动翻转是"逻辑态翻转"非"角度翻转"。
- **关风方法（实测）**：把 l0 关节角压过 0 到负侧（probe2 [G]：+30 外扭矩 200f → ja=−38°、l0 state=0、wind=0；卸力后 120f 稳定不回弹）。joint 限位 ±36°、马达 torque 10。角色玩法向：l0 杆尖 f0 在支点西上 (472.5,415.7)，**角色向东走顶杆尖 → body angle −36°→+36° → ja 过零变负 → state 1→0 风关**（l1 同理向东顶 = state 0→1 桥缩；反向顶回各自的恢复侧）。此为关节符号推演+外扭矩实证，角色实体扳杆待 5.3 首测（§6 P1）。
- 风带覆盖的可站空间：mesa 顶 y256（x800-1024 段）站立时角色上身（y≈221-256）**探入风带**（带底 249.6）→ 风 ON 时 mesa 上持续受西风+阻尼；岸台 y288（x736-832）站姿头部 y≈253 恰在带下 3px，不受风。腔顶（出生台底 y160）至带顶 166.4 之间 6px 死隙。

## 7. 存疑项

1. **H1 终态悬停 (731.0,286.0) 无可见支撑**：feet 角 (726/736,315) 距东岸坡 hyp（x736 处 y320）5px、距水 death 膜顶 y326 有 11px，活体非死非坠 360f+。已排除： damping 稳态（应为 ~208px/s 下落）、岸坡接触（几何不合）。输入时序差异证实 H1 与 probe3 分岔原因（H1 停输入晚一帧、多一帧 west 速度错过 mesa 缘），但悬停支撑机制未解。**5.3 若复现需打 vx/vy/contact 快照**。
2. **F2 vs [G] 同为 +30 扭矩扳 l0，F2 报 windState=1、[G] 报 wind=0**：两探针步序实质相同（F2 停扭条件读 wind.state）。[G] 为准（含卸力后 120f 稳定验证），F2 归探针层疑点存档。嫌疑：首帧 checkState 与扭矩施加的相对时序使 F2 走了"先自动翻转→马达+扭矩平衡"支路。不影响 §3.1 结论（风可被压关且稳定）。
3. **风带几何是代码推算+行为实证，非夹具顶点直读**：geo dump 工具对旋转体不施加 body angle（§3.1 勘误）。后续关卡 dump 风机一律先做角度校正。
4. **平台-地面碰撞语义修正（跨档）**：25 p0 实测穿过 r24 板带（[C] 终位 752 悬于板带下方、板顶探出 y704），证明运动学平台与 Ground 无碰撞。19 号档 §6.3"id26 东端 0.3px 挤靠=碰撞"应更正为"目标位与墙面固有 0.3px 差"。归主会话决定是否回改 19 档。
5. **钻石体心映射口径**：25 实测体心 = objXY+(32,−32)（y=底边口径，12/12）；19 号档 §2 写的是"体心=Tiled 中心"+level2.ts 头注"原版生成时再上抬 1m"。两档口径必有一处表述不精确；对 25 无歧义（12/12 吻合），19 侧不再回验。
6. **出生沉降**：f0 体心 y=96 → 240f 稳态 y≈92.54（上浮 3.46px 后稳）——玩家 body 另有未见顶点的圆形足部夹具（geo 工具只打印多边形），贴地几何以足部夹具为准；不影响机关结论。
7. **b4 缺号**：geo dump 31 体中 b4 无多边形顶点未打印（疑吊板绳段 chain/edge 形）；锚/板位已由 mechanisms 快照直读，无碍。
8. **l0 马达保持的时序细节**：自动翻转后 ja 37.0° 是马达 +4·onis（=−4? 符号按代码 −4·onis=+4）驱动的极限位；[G] 关风后马达 −4 保持 ja −38°（限位 −36+扭矩挠曲）。两态马达方向已实测，但"角色顶杆需要的持续力阈值"未测（杆 density 1.6、马达 torque 10）。
