## 1. r32b 断点真相（两个关键发现）

### 1.1 探针 sleep bug（T2-T8 全部无效）
r32b 的 probe3.mjs T2-T8 全部 fail 且角色水平位移为 0。根因实证（TEMP/r32/dbg3/dbg4）：
teleport 后**不跑 settle 帧**的 body 会 asleep（`awake=false`），而 character.ts 的
ApplyForce 只传 2 参（force, point），wake 缺省 false，**睡体施力无效**。T1 因先跑 30f
settle 而幸免。=> r32b 由此怀疑"隐形地板"，实际是 sleep。**所有分段探针必须 teleport 后
settle ≥30f 再回放。**

### 1.2 WIP01 主干（出生台→c 楔→F736）几何不可能（判定翻转）
- WEDGE_C 几何（build.ts groundShapePts case3 顶点 (0,0)(-1,0)(-1,-1) + 世界翻转映射）
  = **平顶悬臂**：顶面 y=row*32 全平，向西侧尖。01 档把 c@928-960 当斜面跳板是误读
  （r32b grid.mjs 查到的"y704 x820-930 隐形地板"正是 c@800-832 平顶，自洽）。
- 出生台顶 y864 → F736 顶 y736 = **需升 128px**；干净站立跳 kernel 上限 124.2。
  probe3f 实测出生台各 x 最大 rise 仅 102.6（头顶全是 y672 台/y704 块屋檐）。
- F736 正下方全域有屋檐（F736 本体+西侧尖臂），从出生台/地面任何点跳都被压死。
  **结论：32/32_1 东侧玩家的上升口只有两个：p1 电梯（西侧，须 g5 被踩）与
  高处投递的台阶（box/ball）。**

  是**非 sensor 实体**——液体 run 有可站地板，深度 = 0.45 格 = 14.4px：
  护城河涉行面 y878.4、水池涉行面 y238.4、y384 岩浆/绿泥带涉行面 y398.4。

  "浮面游西"的物理真相）；wg 可涉水池（y224 x512-864）连通西岸台↔y224 台。
  液体端盖（CAP_L/R）也是实体楔（顶外扩 0.3m），是涉行面与两岸台面之间的坡。

  → e=NaN → 施力被跳过（S1 首跑"冻结"真相之二）。管线事件 f≥3 无此问题；
  探针 replay 必须先 ≥2f NOIN。
