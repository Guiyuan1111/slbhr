## §0 结论速览

- **引擎同源**：F 与 A–E 是**同一代码库、同一打包容族**（requirejs AMD `define("States/…")` 模块树 +
  同一款社区魔改前置头 GameConfig），关键指纹 createGroundShape ×4 / parseMapPropper ×4 与 D 完全同数；
  **异构点 = 新包 vintage**：Phaser **2.6.15**（@azerion fork，A–E 为 2.6.2）、数据为 **Tiled 1.x 新格式**
  （属性数组化、layers 顺序 Objects 在前、`tiles[].type` 数组式 tileset）、外加 F 专属模块
  （Fairy 角色 / FairyCup 机关 / RespawnManager 检查点 / FakeFairy 树图装饰）。
- **新机关/新机制全集**：① `fairycup`（Objects 层新 tile，唯一新 classNames 键，全 30+1 关共 **104 座**）；
  ② `fairy` 角色（Chars 层新 tile id8，**54 只**，可鼠标拖拽、按组色入杯触发机关组）；
  ③ RespawnManager 自动检查点 + `canRevive:true` 激励广告复活；④ 相机/教程触发对 fairy 的追随与门控
  （`reactToFairies`/`reactToFairiesOnly`）；⑤ temple.json 新字段 wing/rating/difficulty/puzzleLevel/
  skillLevel/state/unlock_key/locked；⑥ dark 关 BGM 分支（levelMusic_dark）。
- **数据口径**：F 关卡**不是 39×29**——30 关尺寸 30×40 … 61×25 全谱系（唯共享教学关 forest_01 是 39×29）；
  **各关 tileset firstgid 排布不一致**（fairies-01 一份排布，其余 31 份另一排布），gid 解析必须逐关按
  自身 tilesets 表归属。Ground.json 与 A/C **语义逐字节等值**（仅键序差），type 全集
  -1,0..9,10,11,12,55（8/9 依旧存在但 F 数据未用）。
- **资产/音频**：音频树与 C **逐文件字节一致（33 文件，0 新键）**；新增图集 NewCharAssets（仙女）、
  MechAssets +25 帧（fairycup_*）、LangsAssets/TutorialAssets、TempleAssets/fairy、

## §2 canRevive / 仙女机制（清单项 2，最高优先）

### 2.1 Fairy 角色（L58979–59357，extends Phaser.Group，构造参数 `(game,x,y,"fairy",group,lockToDeviceGroup,reLockToDeviceGroup)`）

- **物理**：box2d 动态圆 r=0.3（density .1、friction 0、`gravityScale=0`、`linearDamping=5`、bullet、
  fixedRotation），userData="pers"；另有无碰撞 `portal-sensor` fixture（category 4096）与
  `lightProperties:{type:"transparent"}`（**光线穿过仙女**）。
- **骨架**：`anchor` + `elbow` 两零重力体以两条 `b2DistanceJoint` 链接（像提线木偶）；
  玩家用 `b2MouseJoint`（maxForce 3.5 / dampingRatio .3 / frequencyHz 10）拖 anchor；
  未拖时 maxForce 降到 5%。`absoluteMaxSpeed=40`；每帧 Lissajous 摆动施力（闲置漂浮动画）。
- **组色**：`group = Number(String(properties.group)[0])`（**取组号首位数字**），颜色表
  `groupColors = {1:"#ee6633",2:"#55ee22",3:"#57beff",4:"#ffee44",5:"#EC0EF1",6:"#88dddd",7:"#9933FF"}`
  （L52418），group 0/缺省 = 白。
- **锁定语义**（lockToDeviceGroup=i / reLockToDeviceGroup=j，构造 L59033–59043）：生成时若 i 存在 →
  `fairy.locked=true`，`fairy.lockedBy=[组 i 的全部机关]`；每帧 checkLock（L59266–59279）：组 i 任一机关
  state 变真 → 解锁；组 j 任一机关变真 → 重锁。**运行时消费点仅两处**：相机 focus 候选过滤未锁仙女
  （L59692）、教程触发矩形 `!a.locked && rect.contains(…)`（L61934）。**未发现任何物理/拖拽/入杯门控**——
  锁定只影响相机取景与教学提示（存疑项 R1：视觉上无锁形标记，语义弱）。
- **渲染**：NewCharAtlas `flying_body_idle0000–0003`（30fps）+ `flying_glow` 双层辉光，LIGHTEN 混合，
  粒子 MenuAssets/Navy0000 组色渐变；`drawDarkMask`（L59332）= 半径 220px 径向光——**仙女是 dark 关光源**。
- 教学文案（locale L71256）：`tutorial_5: "Sometimes you need a fairy of the right color"`。

### 2.2 FairyCup 仙女杯（L53157–53340，extends BoxedDevice；classNames 键 `fairycup` L59502）

- fixtures：BoxedDevice 的 pusher 形体（默认 `pusherWidth .4 / pusherHeight .3`）+ 半径 **1.3** 的圆
  **sensor**（圆心 = 杯口 `cupOffset (0, .65)` 随 options.rotation 旋转）；本体 mass=0。
- **感应回调**（L53252–53260）：sensor 进出接触时，若对象有 `setExternalTarget`（即 Fairy）且
  **色匹配**（`fairy.group === cup 首位数字 || fairy.group === 0 || cup 首位数字 === 0`）→
  `fairy.setExternalTarget(杯体位置+cupOffset, cup)`，进 `cup.currentFairies`；离开即解除。
- **checkState**（L53326）：`state 0→1` 当 `currentFairies.length>0`（播 lightPusher 音、
  `signal.dispatch` = **接通所属 device group**，语义同按钮）；`1→0` 当清空。
- update（L53289）：state1 时显示 glow（alpha 随仙女距离）；cup 首位数字为 0 时 glow 改染入杯仙女的组色；
  `drawDarkMask` = 半径 60px 径向光（**dark 关光源**）；`ocupy` 十字 5 格（同 pusher，装饰避让）；
  `sounds()` 返回 `"lightPusher"`（**复用 lightPusher 音效集**，无新增音频键）。
- **实跑闭环**（tools/fairy_drag_probe.cjs，§6）：拖 group4 仙女入 group41 杯（首位 4）→
  `state 0→1、occupied 1、fairy.externalTarget 置位`，其余杯不受影响。

### 2.3 canRevive / RespawnManager / 复活流

- `game.json canRevive:true` 消费点**唯一**：GameOverMenu.renderContent（L60509）
  `gameConfig.canRevive && !level.revived` → 加 `ReviveButton`（showRewardedAndRevive →
  `AdManager.showRewardedAd().then(revive)`，L60548）；已复活过则布局退化成双按钮。
- `Level.revive`（L62017–62031）：**销毁重建 pers1/pers2** → `respawnManager.loadLatestCheckpoint()` →
  `ended=false; revived=true` → 恢复光标切换态 → `physics.box2d.paused=false` → 关 GameOverMenu →
  `ui.clock.resumeAt(checkpoint.gameTime)`（**计时器回拨到检查点时刻**）。
- RespawnManager（L61065–61179）：双方都站在地面（feetSensor 法线 y>0.9）、速度为 0、非 dying、无光标
  激活时，**每 ≥667ms 自动抓检查点**，环形队列最多 **5** 份；快照 = pers1/pers2/fairies/all objects 的
  **body transform + 线速度 + 角速度**（不快照 joint/机关内部计时）；`loadLatestCheckpoint` 取
  **4 秒前**最近一份（否则第一份），回放后队列重置为该份。**R 键处理器调用未定义的 `setCheckpoint`
  （L61081）——oracle 潜在 bug**（按 R 会 TypeError，被 jQuery handler 吞）。
- 复活流依赖 h5ads 广告 SDK；无头离线无法走通广告 → **revive 全链路仅静态取证**（存疑项 R2），
  我方复刻可直接实现为"免费复活一次"。

## §3 数据层：关卡/temple（清单项 3、4）

### 3.1 Tiled 格式与逐关 tileset 排布（关键坑）

- **F 是 Tiled 1.x 新格式**，A–E 是旧格式，两边引擎各自适配（parseMapPropper）：
  - F 对象/瓦片属性 = **数组** `[{name,type,value}]`（A–E = 平面对象 `{group:3}`）；
  - F tileset 的 `tiles` = **数组** `[{id,type,properties[]}]`（A–E = 字典 `{"0":{"type":"pusher"}}`
    + `tileproperties`/`tilepropertytypes`）；F 无 tileproperties；
  - F level JSON 顶层多 `compressionlevel/nextlayerid/nextobjectid/tiledversion/version/infinite`；
  - **layers 顺序**：F = Ground/Objects/Chars；A–E = Ground/Chars/Objects（引擎按名取层，无实义）。
- 引擎归一化（F parseMapPropper L61273–61300）：Ground 排首并外链合并（同 A），然后
  `f[gid] = clone(tile)` 且 `properties = (tiles[].properties||[]).reduce(压平)`；对象属性同样数组压平。
  我方解析器照此实现即可复用 A–E 管线。
- **每关 tileset 排布不同**（tools/census_levels.cjs 输出）：
  - fairies-01：`Ground@1, Objects@16, LargeObjects@32, Chars@35`；
  - **其余 31 关**：`Ground@1, Chars@16, Objects@25, LargeObjects@41`；
  - forest_01：`Ground@1, Chars@16, Objects@25`（无 LargeObjects）。
  → **gid→type 必须按各关自身 tilesets[].firstgid 归属**（整表统一映射必错，本次普查 v1 已踩过）。
