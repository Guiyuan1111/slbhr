## 4. 04号档 §3.3 三存疑收敛

### Q1 734.08 实体状态机理 → **已收敛：钉/过 ⇔ 升降柱 tr ⇔ pusher 受压**

- 734.08 柱 = platform device (720,528)，tr=0 延伸位 [705.92,734.08]×[480,576]；收 rate -0.0333/f（2m/s）至 tr=-3 [384,480]。
- QA（静站压板）：pusherTr 仅 0.0569 <0.2 阈值 → 柱不收 → fb 钉 749.7（面 734.08+15.36=749.44+0.26）。
- QB2（v14 同参微爬 spd0.5 x∈[1052,1058]）：pusher→1、pusherTr 0.6069、**platTr 0→-3 逐帧 -0.0333（f118-f194）** → wg 穿柱下通道至 (483.61,540.54)（wgdoor-4-out.json `QB2_crawl_press_then_pass`）。
- v16「platTr=0 双角色自由通行」与本机理矛盾，但其输出件已被覆盖不可审计（04号档 §2.4 日志引用）——**按 QB2 实测机理采信：无受压则无通道**。v16 帧号不作依据。

### Q2 钉位冻结机理 → **已收敛：接触法向抵消，非引擎睡眠；「压面跳释放」仅东向**

- QA 钉位逐帧：walk 每帧 SetLinearVelocity(vx=8.5) 实测 vx=0、awake=true、x 恒 749.7——速度被柱面法向冲量抵消，体从未睡。
- QC（平地同操作对照）自由行走——排除探针操作因素。
- SetAwake 无效 = v17-v19 每帧 SetAwake 的海森堡污染（04号档 §3.4 已记），v20 靶向 wake 后平台段正常——与 QA 互证。
- **QD 压面跳**：钉点跳仅升 ~41px（f104 vy 13.94→f108 -2.17，柱顶东角剐蹭截停，vx 同步归零）→ 垂直落回钉位。西向越柱**不成立**；v20 的「离地 749.70→757.65」即东向释放——与 QD 一致。柱不能靠跳越过（升 123 vs 净跨需求，另见 §3 #3 解析封）。

### Q3 落点相位随机源 → **部分收敛：有界微漂，不改判**

- 同参镜像出口散布 260.84/262.24/262.19（~1.4px）；R9b/c 舱向/台向出口落点 208.88 vs 220.82（~12px）——源自 transport() extra_step 与接触帧相位差。
- 有界且不影响侧向判定（镜像律按触点面定侧，散布 ≤12px 远小于 21.6px 带宽）——封死结论对相位不敏感。

## 5. 诚实缺口

1. **跳跃为探针强制速度**（vy 15.5 world，probe7 先例），本槽未反汇编验证 oracle 原生跳力常数；§3 #3 的解析封以「升 123px、漂速≤walk」为前提。若原生机能不同，需以原生机复测（预期不变：j2 的 0.24px 钉位是引擎实体之所为，非探针参数）。
2. R8a 入口为预置 (344,432)——「攀爬+传送+开门」机制链已证，但「板东段无自然登板」正是终判依据，二者不矛盾；**不存在已证的自然全程**（这正是 NO 判定的内容）。
3. probe1-dump E0 未含柱体 fixture（body 遍历不全）；柱体存在依 tilemap+j2 钉位双证。
4. QD 未复现西向释放（§Q2，判定为「仅东向释放」，与 v20 一致，非缺口性矛盾）。
5. 真实键盘输入的加速曲线未模拟（探针直设速度）；内核复产对照时应以同法（强制速度）对测。

## 6. 终判（只述事实）

**oracle crystal_03 中，wg 在不借助预置/作弊的自然机制下不可到达自己的门（door2）——NO。**
死因唯一且双侧同构：col-8 竖墙 + P7 实体带 + 448 板东段不可登（五重封死的 oracle 同构全数成立，§3.1）。
门机制、西舱、镜像传送链本身健康（§2）。本槽不提交任何处置方案；e_tutorial_fire / fairies-01 家族归属由主会话裁定。
