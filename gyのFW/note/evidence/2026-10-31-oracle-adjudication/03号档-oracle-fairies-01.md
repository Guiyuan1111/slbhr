## 裁决一：l0（lever，object 418）如何被触发

**终判：l0 由「角色在 R13L 顶面（feet≈416）走过杆位区 x∈[280,316]」触发；不能自触发；仙女在常规玩法中无法到达杆位（传送作弊可以压发）。**

逐项证据：

1. **权威数据**：`fairies-01.json` Objects 层 object 418：`{x:256, y:448, w:64, h:64, gid:17, props:{group:5, onis:-1, startPos:1}}`。group-5 联动平台 = object 419：`{type:"platform", x:192, y:448, w:32, h:96, dy:-4, group:5}`（静止位板体 y∈[448,544]，触发后下沉 128px 至 y∈[576,672]，运行时实测 p6：496→624，f02-D）。Chars 层无 group-5 触发体 → l0 唯一触发源是杆体本身。
2. **自触发排除**：f03 全程跑（两轮，1365f / 4735f）中 `lev` 恒为 `0/-36`（未触发位），直到实验结束；无任何 pusher/杯/平台联动会使 l0 翻转。
3. **角色走过触发（正向实证）**：f02-C（r13walkW / r13walkE）：角色站 R13L 顶（feet 416）向西/向东穿过 x∈[280,316]，杆在穿过瞬间翻转（west 向 f46 记录 FIRED），与 pusher/仙女无关。杆的可碰区实测 y∈[379,424]（伸出 R13L 顶面 416 之上），角色碰撞箱（feet−64.3 ~ feet−6.7）站在 416 顶自然覆盖。
4. **仙女常规可达性 = 否**：
   - 杆位在 R13L 顶面之上（y 379-424），R13L 只能从「柱台 419 静止位顶 448」一步登上，而柱台静止位只能从 R17L 顶（544）登上（rise 96）。
   - 仙女从底层（杯区/水体顶 704-800）向西竖井（x∈[32,160]）上行，被 R17L 板带 [544,576]（x∈[0,288] 实心）封顶，最高到 576；杆底 424 距其 24px+，仙女半径 ~12 不可及。向东路径同样被 fill 板带 [544,576]（x∈[576,704]）封死。f04-fairy-stall 实测仙女滞留低层。
   - **作弊参照**：f02-D（fairy-tp-push）直接传送仙女上杆位可以压发 l0 → 证明「杆体响应仙女碰撞」，但常规玩法无路径。
5. **R13L 的唯一非循环入口 = 柱台 419 静止位**（顶 448 → 东跳 160px 同高落 ledgeB[384,480]@448，几何推断，未单独实跑，见存疑①）；而柱台静止位的登台前提是 R17L 顶 544；R17L 顶对动态落体不可用（见裁决二第 4 条）→ **l0 的触发链对角色是循环封闭的**（详见裁决二第 6 条）。

### 2.2 四道封顶（上层隔绝的机制证明）

1. **fill+r16 复合顶（x∈[448,736]）**：r16 板带 [512,544]（x[448,736]）+ fill 板带 [544,576]（x[576,704]）。R21L 层任何东向满跳在 x629 实测撞 fill 底 576，rise 截止 ~43-64px（f03 第一轮 f888-892：feet 629.8 @ x645）；从台阶 x640-657 起跳的箱体几何窗口被 fill 覆盖（起跳点本身在 fill 之下，rise 63.7 即撞），无碰撞窗口仅 [655.4,657.3]（2px，不可行）。f03 第二轮实测起跳 x~665、rise 截止 ~53-60（f944-952），落回 gid5 斜面 (746.5,739.6)。
2. **r19 西面+底面（x≥736）**：r19 板带 [608,640]。唇上起跳实测箱顶入带撞西面：f03 第一轮 f920（737.6, feet 673.5，rise 截止 62.5）；几何上唇/台阶任意合法起跳位均无法在箱东缘越过 736 前使箱底升过 608。r19 底面同时封死 x[736,960] 一切下方升线。
3. **R17L 板带（x∈[0,288]，[544,576]）**：底面实体（爬行空间 rise 截止实测 31.7px，历史探针）；顶面**对动态落体可穿**（f07b drop128walk：自 (170,672) 带速走落，穿过 544 带直落 R25L 800）→ R17L 顶不能作为落点，西向绕行封死。
4. **R13L 板带（x∈[160,416]，[416,448]）**：洞窟（[448,672]）顶盖；R21L 洞窟内满跳 apex feet 533（box 顶 468.7）虽不撞顶，但距 ledgeB 顶 448 差 85px，无法登。R10L[32,160]@320、R7[128,448]@224、R4@128、r9[800,1024]@288、R6R[1024,1280]@192 及双门 (1072/1168,192) 全部位于该四道封顶之上。

### 2.3 杆-柱系统（group 5）的循环性

- 柱台 419 静止位 [448,544]（顶 448）恰好垫在 R13L 底(448)与 R17L 顶(544)之间，是 **R17L→R13L 的上位踏板**；l0 触发后下沉至 [576,672]，与 R17L 底(576)/R21L 顶(672) 齐平，成为无用实心墙（角色 57.6px 高在 96px 空腔内虽可容身，但顶部无出口）。
- 即：**l0 的唯一作用是撤掉上层踏板**；而触发表（R13L）本身依赖该踏板 → 系统 自锁。结合仙女不可达（裁决一第 4 条），**group-5 链在 normal play 中不可用**。
- 对照：上层另有两部 dy+3 升降板（object 415 @x[800,832] rest y[352,448]、object 425 @x[320,352] rest y[128,224]），分别绑 group-3 三钻石（(784,640)/(784,288)/(784,160)）与 group-7 单钻石（(64,160)），全部位于上层 → 与入口无关（f03 全程 p4=400、p10=176 恒定，未动）。

### 2.4 判定边界（诚实声明）

- 以上「不可达」基于已实测的实体语义：gid1 实心、gid2/3/4/5 斜面帽按坡面碰撞、板带六面阻挡、液体 gid7=水（fb 触即死：f03 第一轮 fb 落 (814,750.4) 水带即终局；wg 免疫可立/可沉）、gid6=底池熔岩。
- 未测/不可排双重否定的角落机制（如头部悬挂、钻石体是否实心）不在本次探测范围；就本次 8 个探针、三轮全流程、数百帧逐帧采样的覆盖面而言，未观察到任何一条通路上层的行为。

## 我方内核与 oracle 的语义差异清单

1. **l0 杆体几何**：oracle 杆锚点 (256,448)、可碰区 x[280,316]×y[379,424]（R13L 顶 416 之上）；我方内核 l0 置 (288,480)、杆区 y[440,485]。若按 oracle 数据对齐，杆体应锚在 R13L 台面并上伸 37px。
2. **速度语义（最关键）**：oracle 对 `SetLinearVelocity(±8.5)` 的实速约 **4.25px/f**，且无每帧再施力时速度按 **×0.755/帧** 指数衰减（f06-bumpjump 实测）→ 跳跃 Must 携带「空中每帧重施水平速度」补偿（本档 f03 的 `hold` 参数），我方内核若按名义速度积分轨迹会系统性超冲 ~2 倍。
3. **跳跃速度 16.5**：oracle vy0=16.5 wu/s（=528px/s，g=1000px/s²，rise(f)=8.8f−0.1389f²，apex 139.4@f31.7）与我方内核一致（f08 C1 对照：净空起跳 rise 135 ✓）。
4. **p1 楔板**：oracle object 382 x[160,192]（运行时中心 176/208 视索引），下沉 752→880；03 号档早先记录的「x205.7 楔」与实测阻挡位一致（量级吻合）；「b_g2 box」在 oracle 中无独立箱体——pusher 为 object 413（gid16, 64×64 @(1168,832), group 2）+ 凸台感应区 [1161.6,1238.4]。
5. **R17L 顶面穿透异常**：oracle 中 R17L 带（x[0,288]@[544,576]）顶面对「带水平速度的落体」可穿（f07b drop128walk 直落 R25L），静置/贴放则站立（f07 全 14 面 STANDS）——我方内核瓦片为完全实心，语义不同。复刻时若按完全实心处理，会把「oracle 本就不存在的 R17L 落点」变成存在，属超集偏差（安全方向，但需记录）。
6. **液体语义**：gid7=水（fb 死、wg 免疫可沉入驻留）、gid6=熔岩（底池 [704,928]@928）——与我方「酸/水/岩浆」三液模型不同，oracle 本关仅两液。
7. **杆-柱联动方向**：oracle l0 触发使柱台**下沉**（撤踏板）；我方 03 号档曾按「触发→升平台」建模，方向相反，需按本档更正。
