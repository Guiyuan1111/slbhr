## 1. p1 = platforms[1]（group 4 杠杆阀）—— 门飞走廊的真身

- 关卡定义 `data/forest/levels/forest_04.json` layers[2]/objects[3]：platform x=352 y=672 w=32 h=128 **dx=0 dy=-4 group=4**。
- 内核实测体位：**x[354,382] y[672,800]**（28×128 实心柱），顶 672、底 800（与 [15] 顶面齐平、悬于井口之上）。
- prismatic：state1 = 原位 + (dx,dy)（屏幕）= **下沉 128px**（→ y[800,928] 沉入岩浆下方）。motor ±2，全程约 2s（120f）。
- **单向阀本质**：从门台（128-352@736 实心高原，顶 736）向东越 p1 顶（672）只需 64px——开局方向畅通；从 [15]（800）向西回程需翻 128px —— **最大跳高 124px，恒差 4px**。全图同类 128px 阀共 ≥4 处（p1、b6 沉降位、864 湿坡→高原、柱顶→走道），设计者刻意用 124<128 封死逆行。
- v12 曾按"扳杠杆沉 p1"重构（fb 支线：256面停稳→6f 预走跳 T2 落 (300,160) 成功、边距巨大），但被 §3/§4 三重否决后回退。

## 2. 天穹上限（新发现，杀死了所有"高空越柱"方案）

- 世界顶 `y[0,32]` 通栏实心（(0,32)(0,0)(1248,0)(1248,32)）。
- 角色身高 70.4px（fbF=中心+35.2）：**任何起跳脚位下限 ≈ 32+70.4 ≈ 102**。实测：T2（顶 160）立定跳 vy=-479 被 y89.2 处一帧内钳零（head 撞穹）。
- 推论：**任何"跳过 b6（顶 64）"的几何都不存在**；顶点高度 > 124px 的跳跃也全部被穹顶截断（T2→36 的理论顶点实际只到 ~89-102）。

## 4. 压钮（pusher）与机关链时序冲突

- pusher = **承重按钮**（梯形 1008-1072@429-448，prismatic 轴(0,1) 行程 0.7m，压下 >0.2m 触发）→ group 5 → b6 下沉 128px。
- b6 沉降位 = 226-254@192-328 = **立在 T3 熔岩盆西口的 128px 墙**：fb 的 shelfEast 盆穿越（f~420）被永久封死。
- 按钮唯一可达体 = wg 开局从顶板（992-1248@160，她出生地）坠落的路径体（需落 960-992@320-352 小柱块——32px 窗，且她自然坠线 978→941 落 B）；**触发时机只能早（f~150）**，与 fb 盆穿越（f~420）时序必然冲突。
- 结论：**按钮→b6→T2→T1→杠杆 是宝石支线机关链**（05号档"主线不需要杠杆"结论在方向上正确，只是当时不知道 p1 才是杠杆的靶）。主线回程必须直面 p1。

## 5. 门飞 = 顶点切角工程（当前攻坚）

- 角色脚圆 r2=0.2m（Ø12.8px）贴脚底；躯干梯形在其上。**p1 顶面 y=672 的"脚圆掠面带" = 过柱时脚位 672~685**（脚圆顶 672-13=659 起算，脚位 ≤685 时只有脚圆与台面相切→求解器可西滑掠过；>685 时梯形触角 → 弹射彩票）。
- [15] 顶面 800 → 弧顶恒 676-680（vy 起跳钳制与 vx 换算：vx-0→顶 676；vx-150→vy-473→顶 686.4——**助跑过深反降顶点**，预走 ≤4-5f）。
- 因此唯一可控量 = **弧顶 x 位置**（发射 vx 与发射 x 决定）：需弧顶落在切角 (382,672) 附近 ±10px，使过柱段（354-382）整体处于 672-685 掠面带。旧配置（465 定点立定跳，hold55）弧顶 (388,679) 已是切角模式，但穿透 4-13px 处于求解器角点分辨的边缘 → mc 门段死 ~15%。
- 攻坚中：`DF_REL/DF_PRE/DF_HOLD × FB_REL/FB_PRE/FBHOLD` 全机扫参（`TEMP/r02/sweep-door.sh`），找 ±1f 抖动全 WIN 的切角窗。

## 6. 角色物理补录（本档实测）

- 1f up 点按即跳（a2col 梯跳模式在静面同样有效）；跳高只由 `n.y`（取脚接触法线按 (0,-1) 点积**最优**者）与 |v|≤496 钳制决定。
- 上升段实测 vy 衰减 ≈ 984/s²（顶点 t≈0.5s），下落 ≈ 950/s²；空中输入加速度 976，无输入 τ≈0.136s。
