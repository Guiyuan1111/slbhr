## 2. 硬闸门：bump（832-928@顶 832）

## 3. l0（海滩杠杆 (802,673)）不可达证明

海滩（704-832@672）入口穷举：

1. **东侧熔岩池游入**：需先上 Tower-B 基座顶 (928-960@672) → 需柱顶 (960-1056@544) → 需塔 A 顶/384 盒（仅 wg 顶路由可达）或沟槽跳西（probe15 P-C' 实测：从 544 块起跳弧在 x=1056 处脚位已低于柱顶面，坠落 736slab）→ **fb 无法登柱顶**（东侧最大登高=736slab，P-A' 实测沟槽西坡 45° 落点滑回）。
2. **西侧廊道（704-736@640-672 空腔）**：净空 32px < 57px，不可爬行；其上 608 盒顶被坡盒 (694-736@544-576) 压住，无暴露面。
3. **嘴部（768-800，576-672 空 96px）**：唯一开口但**只进不出**——顶棚 512-576（墙盒 736-800），实测海滩起跳（probe2：795/805,672）最大升高仅 39px（约 60px 处撞棚），需要 96px 才能上坡顶 (768,576)。角色进得去出不来。
4. **顶面直落**：480 条带/墙顶均在 480-512，与海滩间被 448-576 实体完全隔断（col x=800: 448-576 连续实体）。

且 wg 游池必死：致死带=液面下 0.18-1.0m（build.ts 掩码 4369 sensor），滩-池涉水足圆必然入带（池底 704 站立时足圆顶 691.2 < 带底缘 694，重叠 2.8px）。

## 4. 结论（kernel 侧）

- fb：spawn(992,896) → 门(432,832) 必经 bump；bump 键在密封海滩腔内；**无合法输入序列可开门** → kernel WIN 不可达。
- wg：R1-R10 → 行架东端掉落 slab-west(847,448)（probe4 ✓）→ 塔A滑升(878→902,352)（已验）→ 东行走离 → 384 盒 → 柱顶 → 空腔 → 736slab/沟槽 → 底板 → 门(1136)。wg 通路存在（probe15 P-J 差 6 帧走离，待补验），**但单人 door 检查要求双方同时到门**，fb 不可达即整体不可达。
