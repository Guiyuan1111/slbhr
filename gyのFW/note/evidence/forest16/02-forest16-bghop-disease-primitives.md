# forest_16 bgHop 振荡病与修复原语（kernel 实证）

## 病根（TEMP/r16/r16b-dual-route8.mjs 迭代实证）

bgHop phase0 每帧同时做两件矛盾的事:
1. `if (g && spd<40 && n<0.9) set(role,key,false)` —— 坡上松方向让角色滑回落平
2. 但 phase 代码随后又无条件 `set(role,key,true)` 重新按压 → **每帧松-按振荡, 角色钉在坡底滑不动** (~0.05px/帧)

另两条相位门缺陷:
- phase0→phase2 要求 `spd<15 && f-lastMove>6 && n≥0.9` —— 带残速进场永不触发
- 楔在坡底 (vx 钉死 0) 时任何 vmin 窗口永不命中; 16f 超时仅在 vmax>0 时中止 → vmin-only 窗口死循环
- 实证: FB 卡 (797,895) ph=peak 至 f4500; WG 卡 w6 (295,693) ↔ (180-206) 振荡

## 修复原语（已部分入 v8, 全部有效）

1. **跑跳 (running jump)**: 平地按住方向 + 速度阈值内开跳, 不用 bgHop（FB 走廊 f35 vx-261 → f93 西地 已证）
2. **滞跳 (stall-jump)**: 楔死/滞住 |vx|<20 持续 12f → 强制竖直跳 + 空中定向漂移（突破坡底钉死）
3. **平地强入 phase2**: `G && flatN≥0.9 && |vx|<45 && phase===0 → freshS + phase=2`（绕过残速门）
4. **定时空中漂移**: 开跳后按方向 N 帧再松（无空中摩擦 → 松键不减速）
