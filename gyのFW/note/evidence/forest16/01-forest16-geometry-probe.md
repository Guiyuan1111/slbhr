## 轨迹数学结论（kernel 参数: 平跳 rise=123 / 坡跳 454→rise103, 超速归一 vmax=496）

- 走廊 896 → c' 顶 768: 需 rise 128 > 123, **差 5px 不可直跳**（关卡刻意调校）
- c29 柱顶 832 → c30 顶 708: 需 124 > 123, 差 4px 不可直跳; 且柱顶东跳会撞 c30 底 736
- 峰顶 800 → 腔室板 672: 需 128 不可直跳; 但峰顶 800 → d/c 块顶 736 (x 800-864) 只需 rise 64 + 32px 横移 **可行**
- 腔室板顶 672 东行至 992 边缘, 楔底面为下滑顶棚 → **自然坠落即落 c30 顶 708**（非"封锁"——封锁仅针对自下而上）; c30 顶 → 东落 c'/门地板 768 = 60px 下落 + 32px 横移 **易**
- ⇒ FB 真实路线假说: 走廊 →(竖井)→ 峰区 → 峰顶 →(西跳 d/c 顶 736)→ 高室系统 →(东行)→ 腔室板 672 → 东缘坠 c30 顶 → c'/门地板 → 门
- WG 真实路线假说: 门地板 →(西)→ 高室 → 盆地 → 704 板 → 水潭 → 西平地 → 浮块/塔井 → 塔底 896 → 864 平台 → 熔岩跳 (需 vx≥230 全速) → 东侧 → 峰区 → 走廊 → WG 门
