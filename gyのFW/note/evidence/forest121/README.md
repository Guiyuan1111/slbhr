# forest_12_1 不可通关 —— 内核实测证据链

结论：**forest_12_1 在当前内核（HEAD 975dc9e，含 0d24592 风机语义）下不存在全自动通关路线。**
两个门位在物理上均不可达，win 判定要求双门同时 isUp，因此整关不可解。
探针脚本见 `probes/`（复现：`node --import tsx probes/<n>.mjs`，工作目录任意，内部以相对路径引用 `scripts/e2e/routetool/kernel.mjs`，需放回 `TEMP/r121/` 同级运行）。

## 1. 胜利判定（world.ts checkEnd）

- 门体实测：`built.doors.fireboy` 中心 (248,452)（西腔室内），`built.doors.watergirl` (1000,452)（东台）。
- win 条件：`doors.fireboy.isUp && doors.watergirl.isUp`；每门需角色在 64×8 感应带内连续扫帧 21 帧，离开即回退。双门都必须物理站到。

## 2. FB（西门）封闭证明

fb 门位于地下腔室（x160-384，顶棚 slab 224-384@288-320，地坪 448）。全部候选入口逐一证伪：

1. **东嘴链（480 台←512 沟←西壁 (480,480)→(544,416)←顶点 (544,416)）**
   - 西壁唯一峡谷侧入口是漏斗顶点。实测 p38：fb 从东侧落顶点即钉死 (543.9, feet 415.8)。
   - 顶点上方 fin (544-576,320-352) 底缘在 x544 处 y=352，净空 63.9px；实测钉跳仅升 23px（弧线 543.9→570.6→543.8，且方向恒背离来向）→ 钉点不可逃逸，任何方向都不能越顶。
2. **沟槽 (trench 512) 无其他峡谷侧入口**：上方被 slab 与金字塔体封死；slab 东缘被 box (384,256)-(416,288) 盖住；其下 16px 阶梯缝隙体宽不可通行。
3. **腔室西壁空洞（x160, y256-448）← 竖井气柱**：竖井唯一梯子是楼梯 (32,544)→(64,576)→(96,608)→(128,640)（p49 fixture 实测）。实测站平跳升 107.8（5~30f 持握等价，见 rise-table）：
   - 从 (128,800) tip 直跳 apex feet 692.2，梯级东端 640 → **差 52px**；
   - 从 768 台跳 apex 660，但弧到 x128 已落至 ~735 → 差 ~95px；
   - 坑底 896 跳 apex 788 → 差 148px。
   楼梯不可达 → 竖井上部与腔室西壁空洞不可达。
4. **坑区可达性本身已实测打通（排除"路线没找到"）**：p56/p57 实测 缝隙→h2→h1 吊板→坑底 x~230 → 走至 x107 起跳准确落上 (128,800) hyp → 走上 768 台。坑内一切可站点的向上出路全部终止于上述 52px 缺口或 32-48px 净空爬行层（640/576 台，头部净空不足）。
5. **832 台地**（p52 实测可落 x360）向西只能跳回 768 台（同 3），向东为死端爬行阶地。

## 3. WG（东门）封闭证明

1. **东脊顶点 (704,416) 同为单点钉**：p47 实测钉于 (704.1, feet 415.7)。钉跳方向规律实测恒为**背离来向**：fb W-钉（东侧来）→ 东弹；wg E-钉（西侧来）→ 西弹（p58，f465 起跳弹回 676 后回落钉点）。峡谷→东侧水盆的必经 "\" 东面 (704,416)→(736,448) 只能从西侧越过顶点进入 → 被钉封死。
2. **口袋平地 (576-608,480) 越顶尝试**（p66/p67）：站跳升 95-108，但 (a) 高弧在 x~655-660 撞滑槽 (chute) 底缘被向西反折后仍落钉点；(b) 低弧（走跳 77-84）落在 "/" 西面 (672,448)→(704,416) 上滑入钉点。实测漂移上限 ~58px（满右键），弧线顶点最远 x≈663，无法把落点送过 x704 的顶点带。
3. **出生点侧 288 台阶带无西向落点**：p59-p64 实测 288 台面 (x~891-990) 西端为**上行**踏步接塔楼楼梯（x891 处 y280 反升），无任何边沿可落到 448 门台；东侧为上行阶梯回出生壁。门台 (936-1032,448) 垂直上方被 288 台面覆盖，仅西侧盆区可进——而盆区必经第 1 条的钉点。
4. 西沟槽门区（968-1032 下方）不存在从 288 台/阶梯的垂直落入窗口。

## 4. 对 0d24592 语义变更的核对

本关 Objects 层仅 3 个 hanging 吊板（h0 752,560 / h1 496,560 / h2 624,528），无 wind/lever/pusher 实例；吊板摆幅实测 ±10°（p51-53），不构成额外通路。该提交语义与本关结论无关。

## 5. 实测常数备忘（同内核适用其他关）

- 站平跳升 107.8px，5~30f 持握无差；走跳/踩坡跳衰减至 72-95px；coyote 跳更弱。
- 钉跳：单点支撑跳仅升 ~23px，方向背离来向，无法越顶。
- 吊板：摆幅 ±10°（0.18rad），西端飞出点约 (442,736±10)，落点可用空中输入修正 ±40px。
- fb 下沉主线：右走 f10-180 → 角落 (666,451) → 西行入缝 → h2→h1 → 坑底/832 台（p44/p50-53 实测确定性）。
