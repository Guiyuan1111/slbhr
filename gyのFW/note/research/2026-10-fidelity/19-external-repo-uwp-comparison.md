# 19 — 外部 GitHub 仓库对比：w193241125/FireboyAndWatergirl（UWP 旧发行版脱壳包）

> 2026-10-12，用户问询触发。方法：gh api 拉取该仓库元数据 + 全文件树 + 32 关 JSON + 4 个图块集 + temple.json，与本地基线（`Fireboy-and-Watergirl/output/A/` 衍生数据）结构化逐字段 diff。对比脚本一次性使用后已清理。

## 1. 该仓库是什么

https://github.com/w193241125/FireboyAndWatergirl —— 描述"这是我脱壳得出的森林冰火人1源码"。实为**微软商店 UWP 版（WinJS 4.0.1 + AppxManifest 包装）的 appx 脱壳产物**，约 2019 年（pushed 2019-10-26），3 star，无 license，~9.4MB。

**不是可读源码**：js/init.js 仍为 2,365,819 字节的 Closure 压缩混淆 bundle（另有 js/lib.js 1.19MB 与 WinJS 壳）。所谓"脱壳"只是从商店包里解出来，没有反混淆。

## 3. 31 个共享关的数据 diff 结论

- **21 关逐字节一致或仅元数据差异**（tiledversion/layer id/compressionlevel 等无语义字段）。
- **7 关（02/09/15/22/23/26/32）Objects 层 gid 整体 −1**：根源是关卡文件 tilesets 声明的 firstgid 不同（我们 24 / 该版 23），**减 firstgid 后本地 tile id 完全一致，零玩法差异**。注意 21/06 等关两边 firstgid 本就相同（23），故逐字节一致——即两个发行版内部 gid 方案混用，各自自洽。
- **真实差异仅 3 处**：
  1. `forest_03` 风机 rotation：旧版 −89.40440/−88.66191（手绘角）→ 新版（我们基线）标准化为 −90/−90。
  2. `forest_04` 滑轮 `barWidth:2.5` 属性**仅新版有**（官方后来添加）。
  3. `forest_14` 罗马杆 polygon：旧版 `[(0,0),(208,−80),(208,0)]`（闭合三角形）→ 新版 `[(0,0),(208,−80)]`（两点折线，官方删除了闭合点）。
- **音频清单 33/33 完全一致**；Objects.json 图块集结构一致（tilecount 16、tile id 集合相同、均无 per-tile 属性）。

## 4. 对缺陷关判定的意义（重要）

- **forest_21 在旧发行版中逐字节一致**——即 21 的缺陷（fb 门封闭组件零入口）跨发行版存在，不是 output/A 独有。
- forest_14 唯一差异是罗马杆形状，**与 17 号档判定无关**（14 的密封在门台 r8/halfR 楔面 tile 几何，不在罗马杆）；即官方曾改过 14 的罗马杆数据但两版同样不可通。
- 03_1/12_1/09_1 在该仓库不存在，无对照意义。

## 5. 复用结论

**无复用价值**：引擎不可读且我们已超越（内核与更新构建逐帧同构）；关卡数据是旧子集；素材完全重叠。唯一收获是 §3/§4 的发行版演化旁证。
