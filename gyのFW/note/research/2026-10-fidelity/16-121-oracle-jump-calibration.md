# 16 号档：12_1 双引擎跳跃对照——"107.8 跳升常数"证伪为撞头伪值，内核弹道与原版逐帧一致

日期：2026-10-12。背景：r121 交付 forest_12_1"内核不可通关"判定（1c3cd9f），其 §5 实测常数（站平跳升 107.8 等）用于各封 seal 的"差 N px"论证。本档用 oracle（serve-original @8787 原版引擎，只读）做同点同协议对照，修正量测口径。

## 1. 实验设计

- 出生点注入：拦截关卡 JSON 响应改写 Chars 层出生对象坐标（初始条件变更，引擎零改动）；内核侧 `body.SetPosition` 同点位。
- 统一协议：settle 至 f79，f80 按跳（25f 持），feet = −32·y + 35.2，minFeet 取 f80-170。
- 工具与原始数据：`note/evidence/forest121/oracle/`（s31/s32/s33/s34 脚本 + 输出 + oracle 逐帧 trace）。

## 2. 决定性发现：A 台地（feet 831.74）平地跳对照

| | 内核 (rest x=360) | oracle (rest x=379.5) |
|---|---|---|
| rise | 107.8（apex f103） | 118.9（apex f109） |
| 逐帧 | f99 起 x 漂移 +1.3px/f，升速减半 | 全程 x 不动，纯弹道 |

**逐帧 diff**：f80-98 两边轨迹完全同构（0.01px 级，oracle 恰为内核延迟 1 帧的输入派发差）。内核 f99 起偏移 = **撞头**：r20 c11 halfR 半砖 (352-384, 640-672) 底缘 672，内核 x=360 下方 head 顶 (feet−50.72) 于 feet≈723.7 擰其底缘 → apex 723.96 即撞头封顶。oracle x=379.5 处于半砖镂空侧，干净弹道升至 712.84。

**理论核**：原版重力 1000px/s²（oracle LEVEL_INFO gravityYpx=1000, ptm=32 → 31.25 m/s²；内核 build.ts:176 同值），跳设速 v=15.5 → 弹道升程 v²/2g = 122.99px；oracle 实测 118.9（接触/积分损耗 4px）吻合。内核若无撞头应得同值。

## 3. 结论

1. **内核与原版跳跃物理逐帧一致**（同重力/同 v=15.5/同法线调制/同 box2d 迭代 8+3）——无引擎缺口。
2. **r121 §5 "站平跳升恒 107.8（与持握无关）"是撞头伪常数**：832 台地 x≈360 上方 32px 处有 halfR 顶板，5/12/18/24/30f 持握全部封顶于同一撞头线 → "持握无关"假象。真实静止跳升 ≈ **118.9px（feet 口径）**。
3. 由此，r121 各封 seal 的"差 N px"全部偏小 ~11px，需按干净弹道（118.9 + 跳帧速度归一化律 |v|≤15.5 ⇒ 水平速降低 vy + 空中控制 floatForce=30）+ 每点位 head-clearance 复核：
   - 竖井 (128,800) hyp：692.2 → 干净弹道 ~681，梯级 640 仍差 ~41px（seal 方向不变）
   - 768 台跳：apex 660 → ~649，差 640 约 9px（方向不变，余量收紧）
   - 钉跳 26.9/背离来向：无顶板参与，量测干净（维持）
   - 口袋平地越顶（p66/p67 撞滑槽）：滑槽碰撞是真实几何（非量测伪），但弧线参数需按 118.9 重算
4. oracle 钉点状态不可由出生点直接复现（刀锋态位置混沌：D1 滑入沟槽、D2 停在西坡 323 高处）——钉点对照需经"滑入路径"复现，不可直接注入。

## 4. 对 12_1 判定的影响

r121 的"不可通关"**量测基础部分失效**（107.8 伪常数），但方向性 seal（竖井差 41px、768 台差 9px）在干净弹道下仍短缺——**判定暂维持、待全 seal 干净重估**。已派 r121b：以 118.9 干净弹道 + head-clearance 全 seal 复核；seal 破则寻路线（内核→MC≥98%→门禁），seal 立则出 oracle 对照片。
