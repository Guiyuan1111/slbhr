## §3 探针归因（TEMP/vdrift/probe1.mjs，visual-diff.mjs 诊断副本，仓库零改动）

### 3.1 oracle 侧静止性（证伪"oracle 弹簧时变收敛"假说）

物理帧 5→480 逐段抬高钩子目标读 `g.world.scale` / `g.camera.x,y`：

```
f=5..480 全部 {"wsx":1,"wsy":1,"camx":-640,"camy":-480}（7 采样点恒值）
```

原版在量具捕获流中 zoom 恒 1.0、scroll 恒 (−640,−480)，**零时变性**——排除"rAF 驱动的弹簧受 VM 负载影响收敛度"假说。

### 3.2 DOM 入镜实锤（(b) 定谳）

截帧瞬间我方页面层可见性清单（page.evaluate getComputedStyle+getBoundingClientRect）：

```
#menu      none/visible  rect(0,0,0x0)          ← 连接面板确认不在画面
#toast     none          rect(0,0,0x0)
#hud       block         rect(0,0,1280x960)     ← 整层可见
#hud-top   flex          rect(395,8,489x47)     ← 木牌条，压画布顶部
#hud-role  block         rect(414,22,75x19)
#hud-room  block         rect(503,18,348x27)
```

注入 `#menu,#hud,#toast{display:none!important}` 后双 rAF 再截一帧差分（同一次原版帧，消动画漂移）：

|---|---|---|---|
| v1 | （随跑 90.x 档） | 94.71（offset (6,−6)，MAD 8.24） | ~4 |
| v2 | — | 94.67（(6,−6)，top48 81.29） | — |
| v3（存证跑，probe1-result.json） | 91.21 | **94.56**（(6,−6)，MAD 8.47） | **+3.35** |

- **noDom 最差区块 (5,0)72 (11,1)74 (6,0)77 (11,0)80…与 10-13 fvd 的 (5,0)71 (6,0)77 (11,0)84 逐格同型**——画布内容结构自 10-13 无变化。
- noDom 带内三观测 94.56/94.67/94.71（极差 0.15）远稳于 normal 带（极差 2.0）——**DOM 覆盖层还是跑间噪声放大器**。
- Playwright `locator.screenshot()` 语义=按元素包围盒截取**页面合成结果**，压在画布上的 DOM 一并入镜——设计假设"DOM 不入镜"自始即不成立，0.3.33 HUD 木牌化（同批 477cec0 index.html）加大入镜像素量后显性化。`#hud` 层 pointer-events:none（477cec0 注释自述"整层 none 防挡画布"）不阻止绘制入镜，只使 elementsFromPoint 探不到（探针网格空集与此一致）。

### 3.3 缩放假象排除（防误判记录）

- 多尺度互相关（PIL 复算，±48 搜索）：normal 图对 scale=0.98–0.99 较 1.0 高 3.9–4.1 分——**伪象**：把 ours 与"藏 DOM 后的 ours"互比（早期探针存图变量错位）时同样出现，且 noDom 正确图对峰值回到 scale=1.0 附近（0.99 仅 +1.8，在 PIL BICUBIC vs 浏览器 drawImage 的滤波底噪 ±2 内）。
- 我方目标缩放精确解（GameScene.updateCamTarget）：forest_01 出生间距 c≈|Δgx|+400≪1280、d≪896 → i=j=1；40×30/30×... 格钳制 `h*40*32>1280` 不触发 → **camTScale=1.0**。
- oracle 实测=1.0（§3.1）。**两侧 zoom 均为 1.0，无缩放差**；最优对齐 (6,−6)@480 ≈ 原生 (16,−16)px 是已归档的相机参照语义差（flashvd 报告"世界内容刚体偏移右16/上15~17"、38 号档 F2"settled scroll 系统差 ±16px"互证）。
- ⚠ 38 号档"冻结 zoom 0.9231 vs 1.0"为**假钟冻结瞬态**（其协议在 enterLevel 闸口冻结、弹簧未收敛），与量具 settled 时刻（zoom 双侧=1.0）不矛盾——两档并读时请以本节为口径桥。

### 3.4 三分类归因定谳

- **(a) 0.3.35 templeTreeBake：0 帧。** 量具两侧捕获流均不含选关画面：oracle 走 `state.start('level', levelData)` 直跳（visual-diff.mjs NAVIGATE），从未 start temple 态；我方走 `?level=forest_01` 深链（main.ts"深链时面板直接可见，跳过画布选关"），截帧在 started+1s 的 GameScene（全屏不透明显示于 Temple 之上）。0.3.35 代码面 f366e02/8e56200/fa17e12 全部 TempleScene/templeTreeBake/档卷工具域（git show --stat 核）。旁证：我方截帧与原版关卡画面 noDom 匹配 94.6%（若是选关画面匹配率不可能过 90）。
- **(b) DOM 入镜：定谳，主因。** 全部我方帧系统性净扣 3.35–4.1 分（§3.2）；0.3.33/0.3.36 两批连接界面 DOM 改动中，真正入镜的变更面=0.3.33 批内的 HUD 木牌化+邀请钮（0.3.36 的 index.html 177 行改动 grep `#hud` 选择器=0，纯 #menu 域，截帧时 display:none，**对量具零影响**）。量具 bug 定性：设计假设与 Playwright 截图语义不符。
- **(c) 真回归候选：无定谳项。** DOM 除外后画布内容与 10-13 结构同型（§3.2），残差 94.56–94.71 vs"10-13 纯画布等效值 ≥96"的 −1.4~−1.9 落在环境噪声带（±1.5–2，r8 报告与本次 repeat3 极差双证）。窗口内 client 提交逐个过堂无一能触 idle 初始态画面（§1.2）。**遗留 Drill-down 见 §3.5。**

### 3.5 (c) 下钻未竟事项（停止门关闭，程序留档待核）

预备好的决定性实验（未跑）：`git worktree add --detach <TEMP> 6fec4a3` + `ln -s node_modules` + `sync-assets && vite build` + probe1.mjs 改 ROOT 指 worktree，同窗跑 noDom——若 noDom@6fec4a3 ≈ noDom@HEAD（±0.3），(c) 关闭归环境；若低 ≥1 分，则 10-13→10-18 窗内存在画布微回归候选（届时按 §1.2 清单二分）。产物对照锚：96.05 时代 normal 含旧轻量 HUD 文本入镜，故其"纯画布等效值"应 ≥96.05，与今日 noDom 94.56 的差是 (c) 的上界。
