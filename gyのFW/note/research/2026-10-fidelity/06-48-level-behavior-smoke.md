## 1. 方法

对 48 关（`data/tutorials/levels/forest_01` + `data/forest/levels/` 47 关）逐关构建完整物理世界（`parseLevel` + `World`），双角色零输入步进 600 帧（10s @ 1/60），按用户冻结标准逐条实现：

| 冻结标准 | 实现口径 |
| --- | --- |
| 出生站稳：≤2s 内 \|vy\|<0.5m/s 且持续 1s 不再下坠 | 最小 t≤120 帧，使 [t, t+60] 内 \|vy\| 恒 <16px/s（0.5m/s=16px/s）且窗口净下坠 ≤1.6px（5cm） |
| 角色不陷入地面（脚底不低站立面 5cm） | 脚底 = 体中心 + 1.1m×32=35.2px（躯干圆 y2=−0.9m + 脚圆 r=0.2m）；站立面 = 脚底最终位置正下方 Ground 网格首支撑面：实心格取格顶 row×32，斜面格取脚心 x 处斜面高（`/`: y=row×32+(32col+32−x)，`\`: y=row×32+(x−32col)），液体行段取下半实体盒顶 row×32+14.4px（`build.ts` 中段盒 y=−0.45m，即"齐腰深"支撑面）。判定 pen = 脚底 − 站立面 ≤ 1.6px |
| x/y 有限、不掉出 | 逐帧查双角色四元组有限；\|x\|,|y| < 关卡尺寸+200px |
| 无 NaN | 角色逐帧；全部刚体（含机关外的摆/滑轮/罗马杠等）每 60 帧经 `world.GetBodyList()` 全扫 |
| phase 保持 playing | gameover → 记"出生即死"（无输入下死亡只可能源于出生点与液体/机关贴合，属关卡数据问题，单独成清单而非通过）；won 亦记异常 |
| 机关体位置有限、无飞出 | lever/pusher/platform/prop 每帧 30 采样，距初始位置 >30m（960px）记飞出 |
| 刚体总数不增长 | 0 帧 vs 600 帧 `GetBodyList` 计数（钻石被拾取只会减少，记 info） |

机关初始位置、每关地形/液体/出生点网格均从关卡数据实算，无任何写死数值；明细 JSON 落系统临时目录（`os.tmpdir()/fw-smoke-48-results.json`，不入仓库）。
