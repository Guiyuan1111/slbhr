## 1. r14 判定要点（内核侧，未污染）

- 封印链（内核实测）：
  1. **上升量不足**：干净弹道升 124.2（jumpVelocity 15.5 + 重力 31.25 理论 123）；登门台需 ≥131.2 —— **差 3.8px 系统性短缺**（r12@384 → apex feet 259.8 > 256）。
  2. **45° 双楔面**（决定性）：r8 halfR c8 + r7 halfR c9 的防护面下缘共线 **x+y=544**；三次西上跳停滞点头圆心到线距离 15.42/15.56/15.63 ≈ r15.36（切线截停，上升仅 ~83 即被截停，永达不到角点搭接窗）。
  3. 唇口跳：r8 板底 288 vs 头圆顶，板下起跳 38.8 即顶头。
  4. 风浮顶棚：风柱内 bob 上限 feet 338.6（头顶 316.8），距板底 288 差 28.8px；浮空跳零位移。
  5. 距离墙：roman 顶/塔顶/箱到门台缺口 240-500px，最大跳跃漂移 ~168px。

## 4. oracle 探针工程注意事项（复用必读）

1. **context viewport 不得自定义高度**：`newContext({viewport:{1280,960}})` 会让原版关卡加载必挂（"Cannot read properties of null (reading 'load')" / "undefined (reading '2')"）——用默认 viewport（1280×720）即可（s35 实证，s33b 的 B/C 场景失败疑同源）。
2. **每场景独立 browser 实例**：同浏览器第二个 context 加载关卡易挂（s33b/s31 实证）。
3. READY_PROG 必须带 `Array.isArray(temples) && length>0`。
4. 出生点 object y + 32 为出生中心，生位若高于目标面 >2 格注意落点上方砖体（14 的 r8 门台砖 x≤256 —— 生 x=256 顶上就是门台底）。
5. oracle 输入派发比内核晚 1f（capture 钩 Step 前注入）。
