# 0.2.0 — 像素级视觉复刻（forest_01）

以本地原版（`Fireboy-and-Watergirl`，只读参照）实测配方重建客户端渲染。联机协议与物理内核零改动。

## 渲染复刻

- 地面走原版管线：ForeGround 岩壁纹理 × MaskBox 蒙版合成，外加 3.5px 黑描边（膨胀近似）与右下 8px 软投影，canvas 一次性合成、不依赖 WebGL 滤镜
- 关卡画布 1312×992（1248×928 四周各 32px 边距），与原版 groundTexture 同布局
- 层序照抄原版 layers：背景/门 → 教学文字 → 钻石/机关 → 地面 → 拉杆 → 角色 → 前景装饰 → 液体 → 浮尘 → 时钟
- 机关贴图化：推块 110×86 + 组色亮层、拉杆底座+杆（静止左倾）、银色推箱、三段式移动平台（scale 1.05/0.95）
- 前景装饰按原版分派规则撒点：墙内裂纹 / 苔藓 / 地表幼苗 / 斜坡藤蔓（固定种子复刻分布）
- 液体三池（岩浆/水/绿泥）Left/中/Right 三段精灵 30fps 随机相位
- 角色 legs+head+glow 同心叠加，scale 0.95，跑/跳/落/待机 30fps，死亡烟效
- 通关演出：BGM 切换 → 门开楼梯 → 结算板（钻石/用时/星级石碑）→ 继续按钮重开
- 顶部藤蔓时钟 02:00 倒数、画布内红/蓝钻石计数；18 颗漂浮尘埃

## 音效

- 跳跃（火/水各一）/ 钻石 / 死亡 / 开门 / 通关 BGM 接入官方 mp3

## 修复

- 客户端图块集预取后同步供给 parseLevel（此前 Promise 直传导致全部地块类型退化为实心、液体斜坡消失）
- MaskBox 实心帧名 5 位数字；decor 帧名带 0000 后缀；机关 gid 用图块集本地 id（0/2/4）
- Phaser `forceSetTimeOut` 修复内嵌浏览器 rAF 冻结导致的场景卡在 Boot
- `start-lan.bat` 移除 `chcp 65001`（GBK 菜单乱码）

## 验收

- 内核 10/10 测试通过；双窗口创建/加入房间、方向键移动双端同步实测通过
- 与原版同屏对照迭代 4 轮；视觉评审 9 项全部一致，无一眼可见差异（对照样张见 `note/report/visual-0.2.0/`）

## 已知差异（有意为之）

- 教学文字静态全显 7 条（真实原版行为）；参考页（8099 魔改版）是渐进显示

- 顶部联机状态栏为我们的联机 UI
